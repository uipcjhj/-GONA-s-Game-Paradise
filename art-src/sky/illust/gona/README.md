# 고나 에셋 — 용도 구분 (서로 대체·혼용 금지)

| 구분 | 용도 | 스타일 · 시점 | 파일 |
|---|---|---|---|
| **선택 화면 원화** (`illust`) | 캐릭터 선택 화면의 큰 그림 | 1990년대 셀 애니메이션풍 2D, **얼굴이 보이는** 역동적 포즈 | `A_illust_raw.png` / `A_illust_clean.png` |
| **얼굴 아이콘** (`portrait`) | 선택 UI·HUD 얼굴 | 셀 애니메이션풍, 얼굴 클로즈업 | `B_portrait_raw.png` / `B_portrait_clean.png` |
| **필살기 컷인** (`cutin`) | 필살기 발동 연출 | 셀 애니메이션풍, 얼굴 보임 | `C_cutin_raw.png`, `C_cutin_2x1_crop.png` |
| **전투 스프라이트** (`sprite`) | 실제 게임 플레이 | **픽셀아트, 후방 3/4 탑다운 뒷모습**, 위쪽으로 비행 | `rear/` 의 시안이 기준 (최종 시트는 승인 후 제작) |

- 원화(illust·portrait·cutin)를 전투용 뒷모습으로 바꾸지 않는다. 뒷모습(`rear/`)은 전투 스프라이트 제작에만 쓴다.
- 두 종류는 아트 스타일이 다르지만 고유 특징(연두 익룡 후드·노란 톱니 볏·말린 머리카락 한 가닥·주황 날개·빨간 스카프·고글·갈색 벨트/부츠)은 일치시킨다.
- `discarded/` 의 앞모습 스프라이트 시트는 폐기 — 사용 금지.
