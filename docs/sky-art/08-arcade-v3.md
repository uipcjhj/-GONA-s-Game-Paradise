# GONA's Sky Adventure — 아케이드 완성도 3차 개선 (스테이지 1)

개발 브랜치 `claude/gonas-sky-adventure-dev-ow01sy` 전용. 정식 사이트·main·Food Adventure 는 수정하지 않음.

## 1. 보스전 버벅임 (최우선)

### 원인 분석 (e8f664f)
| 항목 | 이전 | 문제 |
|---|---|---|
| 효과음 | `new Audio()` → 매번 `cloneNode().play()` | iOS Safari 에서 미디어 요소 생성·디코딩이 메인 스레드를 막음. 보스 피격음 초당 8회 + 격파음 → 보스전 끊김의 주원인으로 판단 |
| 캔버스 크기 | `floor(폭×DPR/180)` 배 → iPhone(DPR 3) 1080×1920 | 매 프레임 207만 픽셀 + 화면 전체 반투명 덮기 2장 + 배경 확대 2장 |
| 글자 | `fillText` 9번(외곽선 8 + 본문)/글자열, 점수·콤보·떠오르는 숫자 매 프레임 | iOS 캔버스 글자 렌더링이 느림 |
| 적 탄 | 탄마다 save/translate/rotate/scale drawImage + 반투명 fillRect | 탄 100발 = 수백 번의 상태 변경 |
| 객체 | 매 프레임 `filter()` 로 배열 새로 생성, 플레이어 탄마다 `new Set()` | GC 증가 |
| 파티클·폭발 | 상한 없음 | 보스 격파·폭탄 때 급증 |

### 수정
- **Web Audio**(`src/sky/audio.ts`): 디코딩된 버퍼 재사용, 이름별 동시 재생 수·최소 간격, 컴프레서 + 최종 리미터
- **고정 2배 캔버스**(360×640) + CSS 확대: iPhone 기준 픽셀 수 **1/9**. 스프라이트가 모두 2배 격자라 화질 손실 없음
- **미리 굽기**: 배경 덮개색을 배경·소품 이미지에 합성(매 프레임 전체 덮기 제거), 적 탄은 크기·16방향 회전별 완성 이미지 캐시, 글자는 이미지 캐시
- **객체 풀 + 제자리 압축**: 탄·파티클 재사용, 배열 재생성 없음, `Set` 제거
- **상한**: 파티클 220 · 폭발 36 · 이펙트 70 · 떠오르는 글자 10 · 적 탄 320
- **진단 화면**: 일시정지 → `성능 표시` (또는 URL 에 `?perf`) — FPS · 평균/최대 프레임 시간 · 갱신/그리기 ms · 20ms 넘은 프레임 수 · 탄/적/파티클 수 · JS 힙(지원 브라우저만)

## 2. 슈팅 그래픽 · 타격감
- 고나 탄: 흰 다이아몬드 머리 + 청록 불꽃 꼬리 '에너지 화살'(2프레임 깜박임), 레벨별 크기·모양(Lv3 금빛 심+날개, Lv4 측면 파동탄)
- 머즐 플래시 3프레임, 적중 스파크(청록), 보스 장갑 금속 파편(주황·회색), 보스 약점(유리 돔) 분홍 결정 파열 + 피해 1.5배, 충격파 링
- 히트스톱: 차지샷·폭탄·중형 격파·보스 단계 전환·보스 격파
- 보스 격파: 2.6초 점점 잦아지는 연쇄 폭발 → 대폭발 링 2중 + 섬광
- 탄 구분: 적 탄 = 둥근 형태 + 짙은 외곽선 + 맨 위 레이어 / 내 탄 = 길쭉한 청록·금빛, 외곽선 없음, 88% 불투명, 아래 레이어
- 에셋: `tools/build-sky-fx.py` → `public/assets/sky/v2/fx/*.png`

## 3. 타이틀
- 흐름: 타이틀 → START → 캐릭터 선택 → 스테이지 (월드맵 연결 유지: 타이틀·일시정지·결과 화면에서 월드맵으로)
- 원화(Higgsfield): 키 아트 `v2/title/keyart.jpg`, 로고 `v2/title/logo.png` (원본 `art-src/sky/title/`)
- 연출: 로고 낙하·흔들림, 원화 등장, 구름 흐름, 별빛 입자 상승, PRESS START 깜박임, 흰 섬광→남색 전환

## 4. 사운드 (전부 오리지널 합성)
- `tools/sky-audio/synth.py`(악기·드럼·리버브) + `songs.py`(작곡) + `sfx.py`(효과음) → `public/assets/sky/audio/`
- 기존 Food Adventure mp3 사본은 슈팅게임 폴더에서 제거(원본 저장소는 그대로)
- BGM: title(D, 100bpm) · select(F, 160bpm) · stage1(D단조 판타지 록, 160bpm) · boss(C단조, 170bpm) · clear · over
- 반복: 주기 렌더링 + loopStart/loopEnd → 이음매 없음. 경고 시 스테이지 곡 1.4초 페이드아웃 → 보스 곡 0.5초 페이드인
- iPhone: 첫 터치에서 AudioContext 해제(그 전 예약 곡은 해제 즉시 재생), 화면 숨김 시 일시정지, BGM 은 항상 1곡

## 5. 가족 필살기
- 게이지(SP): 적에게 준 피해·격파·아이템으로 충전(일반 진행 약 25~30초). 폭탄(고나 전용 3발)과 별개
- 버튼: 차지 · 필살(동료 얼굴 + 게이지) · 폭탄 — 3개
- 발동: 원화 컷인 0.62초(그동안 게임 0.3배속 + 무적) → 캐릭터별 효과

| 캐릭터 | 필살기 | 효과 |
|---|---|---|
| 고나(폭탄) | 황금 익룡의 포효 | 황금 익룡이 솟구치며 화면 전체 탄 소거 + 광역 피해 |
| 엄마 | 하트 스톰 | 하트 마법진 + 유도 하트 14발 × 9파 |
| 아빠 | 스팀 브레이커 | 굵은 증기 레이저 2.3초(적 탄 소거, 고속 다단 피해) |
| 이모 | 스타 캐논 버스트 | 별빛 유도탄 0.1초마다 5발 × 2초 |
| 할머니 | 골든 힐링 | 체력 +2 · 5초 보호막 · 주변 탄 정화 |
| 할아버지 | 가디언 실드 | 5초 방패벽이 적 탄을 막고 은빛 창으로 반격 + 창 9발 일제 투척 |
| 삼촌 | 메가 인벤션 | 발명 메카가 유도 미사일 연사 후 드릴 돌진 |

## 6. 햅틱
- 표준 `navigator.vibrate` 가 있는 기기(주로 Android Chrome)에서만 짧게 진동. iPhone Safari 는 이 API 가 없어 자동 비활성(일시정지 메뉴에 '이 브라우저 미지원' 표시). 비표준 우회는 쓰지 않음
- 대신 화면 흔들림(설정: 끔/약/보통) · 히트스톱 · 충격파 · 사운드로 타격감 보완
