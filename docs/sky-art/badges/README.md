## 2. 새 배지 디자인 시스템

- **형식**: 64×64 도트 픽셀아트 원본 → 게임에서 정수 배율(1·2·3배)로 표시 · 투명 배경 PNG
- **조형 언어**: 2px 진갈색 외곽선 · 6단계 금속/보석 색 띠 · 왼쪽 위 빛(윗면 1단 밝게, 아랫면 1단 어둡게) · 보석은 왼쪽 위 흰 점 하나
- **얼굴 금지**: 가운데에는 조건을 상징하는 16×16 문양을 2배 도트로 (보스 상징 · 하트 · 폭탄 금지 · 별 · 카메라 · 무기)
- **틀 = 종류**: 방패 문장(보스) · 햇살 훈장(도전 조건) · 별+날개(랭크) · 육각 문장(동료) · 폴라로이드+원판(사진) · 월계수 원판(난이도) · 날개+왕관+보석(MASTER)
- **등급 = 재질**: EASY 동 · NORMAL 은 · HARD 금 (같은 형태, 별 1·2·3개)
- **리본 색 = 계열**: 보스 빨강 · 노미스 파랑 · 랭크 보라 · 동료 = 동료 대표색 · 사진 분홍
- **잠김**: 같은 실루엣을 어두운 금속 단색으로 · **획득**: 원래 색 + 은은한 광택(표시 때 CSS 반짝임 한 번)
- **확대 화면**: 3배 그림 · 이름 · 의미 · 획득 조건 · 획득일 · 신규 획득 때 0.6초 '훈장 수여'(내려와 꽂히는 움직임 + 빛 한 번)
