# 고나 신규 스프라이트 게임 연결 · 플레이 테스트 (개발 브랜치, 미배포)

## 적용 범위
- 전투 중 고나만 `public/assets/sky/v2/chars/gona/sprite.png` 로 그림 (시트가 없으면 기존 그래픽으로 자동 대체)
- 선택 화면 원화·얼굴 아이콘·컷인, 다른 가족, 적·보스, 게임 로직(체력·탄·판정·점수) **변경 없음**
- 변경 파일: `src/sky/assets.ts`(시트 선택 로드), `src/sky/engine.ts`(애니메이션 상태·그리기 순서), `src/sky/SkyGame.tsx`(차지 버튼 캡처 해제 시 차지 해제 안전장치 1줄)

## 확인된 점 · 남은 일
- **실기 iPhone Safari 미검증** — 이 환경은 Chromium 에뮬레이션만 가능(WebKit 미설치). 실제 기기에서 확인 필요.
- 테스트 중 차지 버튼 해제가 안 되는 현상은 테스트 도구의 멀티터치 해제 방식 문제였음(단일·멀티 해제 모두 실제 이벤트로는 정상). 그래도 iOS의 터치 취소에 대비해 포인터 캡처가 끊기면 차지를 해제하도록 보강.
- 차지 최대 프레임 오라가 고나 실루엣을 많이 덮음(탄막은 위에 그려져 보임). 승인 시 유지 결정 사항.
- DPR 2 기기에서는 스프라이트 1픽셀이 기기 1.5픽셀이 되어 도트 굵기가 미세하게 고르지 않을 수 있음.
- 강한 기울기 좌우 비대칭·승리 동작 크기는 지시대로 그대로 둠 — 플레이 화면에서는 큰 문제 없어 보임.
