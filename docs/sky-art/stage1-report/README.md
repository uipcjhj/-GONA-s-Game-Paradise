## 구현한 기능
- 배경: 원경 하늘 + 원경/중경/근경 3단 패럴랙스, 60초 대본으로 고성·유적·시계탑·비행선이 지나감, 중앙은 비워 탄막 가독성 확보
- 편대: V자 드론, 좌우 횡단 전투기(진행 방향 회전), 급강하 와이번, 정지 포탑, 드론 떼, 중형 건십 — 적마다 다른 탄막(조준 3방향 / 고속 바늘 2연사 / 화염구 / 회전 원형탄 / 대형 원형탄+측면 바늘)
- 타격감: 피격 번쩍임, 소형 1단·포탑 2단·건십 6단 연쇄 폭발 + 파편 + 흔들림, 보스 격파 시 연쇄 대폭발·섬광
- 보스: 경고(붉은 화면·경고 띠·문구) → 등장 → 단계별 패턴, 2단계부터 파손·날개 스프라이트로 변신, 단계 칸이 있는 체력 바
- 고나: 승인 스프라이트 그대로, 에너지 볼트 탄, 차지샷 발사 섬광·광선, 폭탄 시 고나 컷인이 화면을 가로지름
- 동료 6명(삼촌 신규): 엄마 하트 광역 · 아빠 증기 광선 · 이모 별빛 유도탄 · 할머니 폭발 물약(+주기 회복) · 할아버지 관통 창 + 방패 · 삼촌 지그재그 전기 유도탄. 모두 비행 스프라이트(서 있는 그림 폐기)
- HUD: 상단 아케이드 띠(체력·폭탄·점수·무기 레벨·차지 게이지), 아이템을 P 보석·점수 메달·하트·폭탄으로 교체
- 선택 화면: 큰 셀풍 원화 + 이름판, 일반/차지/필살기 소개, 전투 스프라이트 미리보기(고나+동료 애니메이션), 6명 로스터·1P 커서, 좌우 전환 애니메이션
- 모바일: 세로 여백이 충분한 화면은 차지/폭탄 버튼을 전투 화면 밖 하단 바로, 아니면 작게 반투명 오버레이. 양옆 여백은 어두운 색

## 남은 문제 · 다음 우선순위
1. 실기 iPhone Safari 확인(성능·터치·소리). 대형 PNG(원화 6장 각 ~0.3–0.6MB) 로딩 시간 확인.
2. 아빠 증기 광선·할아버지 방패 이펙트는 아직 코드 그림(밝은 사각형·기존 방패) — 전용 이펙트 에셋 필요.
3. 배경 원경이 반복되는 패턴이 보임 → 원경 2장째 또는 스크롤 중 변화(스테이지 후반 성채 구간) 추가.
4. 적은 한 장짜리 스프라이트(프로펠러·날갯짓 애니메이션 없음) → 2~4프레임 애니메이션 추가.
5. 보스 3단계 전용 외형·특수 패턴(레이저 등) 미구현(2단계 외형 재사용). 중간보스(킁카 캐논) 미배치.
6. 차지 최대 오라·강한 기울기 비대칭·승리 동작은 승인 상태 유지(지시대로 미수정).
7. 배경음·효과음은 기존 푸드 어드벤처 사운드 재사용.
