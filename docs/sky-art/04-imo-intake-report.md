## 2~6 항목별 판정
| 항목 | 판정 | 근거 |
|---|---|---|
| 선택 화면 원화(`illust.png`) | **디자인은 사용 가능 / 현재 파일은 납품 불가** | 마법포 + 보라 망토 + 줄무늬 크림 상의 + 크림 바지 + 선글라스 + 둥근 얼굴 모두 방향에 부합. 단 ① 알파 없음, ② 높이 1312 < 규격 1536 (비율 0.91, 규격 2:3), ③ 아래 "배경 제거" 문제 |
| 체크무늬 제거 | **부분 가능, 품질 부족** | 외곽 연결 배경은 깨끗이 제거됨(불투명 영역 1193×1307). 그러나 (a) 머리카락 사이·귀 뒤에 체크무늬 조각이 남음, (b) 총구 섬광의 **반투명 글로우가 흰 배경에 구워져** 어두운 배경 위에서 흰 테두리로 보임(복구 불가), (c) 우측·상단 섬광이 캔버스 가장자리(0~3px)까지 닿아 잘림 가능, (d) JPEG식 압축 노이즈 |
| 얼굴 아이콘(`portrait.png`) | **분리 가능(부분)** | 얼굴 영역이 원본 해상도로 약 300~380px → 256×256으로 줄이는 것은 품질 손실 없음. 단 배경이 깨끗한 알파가 없으면 불투명 단색 배경 합성이 필요 → 머리카락 가장자리 체크 조각 때문에 현재 파일로는 깔끔하지 않음 |

### 스프라이트 시안(`sprite_layout_reference.png`) 상세
- 격자 4열×8행은 맞으나 셀이 약 **144×121px(정사각 아님)** 이고 캐릭터는 셀 안에서 약 90×75px → 96×96으로 맞추려면 **약 0.7배 이하로 줄여야 하고 도트가 뭉개짐**(원본도 정수 도트가 아닌 흐릿한 확대 이미지).
- **전 프레임이 빗자루(+지팡이) 버전** — 확정된 마법포 방향과 다름. 디자인을 새로 그려야 하므로 추출·재사용 불가.
- 행 구성이 규격과 다름: 규격은 fly·bankL·bankR·shoot·charge·bomb·hurt·win. 시안은 앞 2행 비행류, 3~5행 발사/이펙트류, 6행 놀람/피격류, 7행 지팡이 든 포즈, **8행은 캐릭터가 아닌 연기·이펙트**.
- 체크무늬 배경이 구워져 있고 알파 없음.
- 레이아웃 시트 안의 **얼굴 아이콘 시안**(약 335×327px)은 빗자루/지팡이와 무관해 크기상 사용 가능하나, 망토 색이 남색 계열이라 마법포 원화(보라 망토)와 불일치, 도트풍 화풍도 원화(셀화풍)와 다름.
- 구역 표시: `docs/sky-art/imo-intake/02-layout-regions.png`

## 디자인 기준 점검 (사용자 기준 vs 시안)
| 기준 | concept 시안 |
|---|---|
| 둥근 얼굴·볼살·체형 유지 | 부합 |
| 옆에서 낮게 말아 묶은 쪽머리 | 부합 (귀 뒤 낮은 쪽머리) |
| **검은 머리** | **불일치 가능성** — 짙은 갈색에 붉은 하이라이트로 보임. 의도한 색이면 검정으로 확정 필요 |
| 줄무늬 크림 상의 / 크림 바지 | 부합 (줄무늬는 보라·남색) |
| 보라 망토 + 별빛 마법포 | 부합 |
| 선글라스 | 부합 (원화). 작은 스프라이트에서는 **얼굴 대비 큰 검은 렌즈 2개 + 금색 귀걸이**가 식별 포인트가 되도록 의뢰 필요 |
