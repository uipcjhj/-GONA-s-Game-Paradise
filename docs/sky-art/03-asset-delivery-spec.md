# 3 — 신규 아트 납품 규격 (ChatGPT 제작분 → 게임 적용용)

원화·게임용 에셋은 ChatGPT에서 제작하고, 최종 승인된 파일을 받으면 그때 게임에 적용합니다. **그 전까지 게임 그래픽은 바꾸지 않습니다.**
(ChatGPT 이미지는 픽셀이 정확히 맞지 않는 경우가 많습니다. 납품 후 슬라이스·정수 배율 정리·팔레트 정리는 제가 해 드릴 수 있습니다. 가능하면 아래 규격에 가깝게 요청해 주세요.)

## 에셋 용도 구분 (건버드식: 선택 화면 원화 ≠ 게임 스프라이트)
| 에셋 | 어디에 | 스타일 |
|---|---|---|
| `illust.png` | 캐릭터 선택 화면의 큰 원화 | 1990년대 셀 애니메이션풍 2D, 얼굴이 보이는 역동적 포즈 |
| `portrait.png` | 선택 UI·HUD 얼굴 아이콘 | 셀 애니메이션풍 |
| `cutin.png` | 필살기 컷인 | 셀 애니메이션풍 |
| `sprite.png` | 실제 전투 화면 | **픽셀아트, 후방 3/4 탑다운 뒷모습**, 화면 위쪽으로 비행 |
- 원화와 스프라이트는 서로 대체하지 않는다. 스타일은 다르되 캐릭터 고유 특징은 일치.
- 캐릭터 선택 화면(구현은 승인 후): 큰 원화 + 이름·직업·공격 특성 + **작은 전투 스프라이트 미리보기(뒷모습 비행 애니메이션)** 를 함께 표시.

## 폴더와 파일명
`public/assets/sky/v2/chars/<id>/` — id: `gona mom dad imo halmeoni halabeoji samchon`
| 파일 | 규격 |
|---|---|
| `illust.png` | 선택 화면 전신 원화, 세로 ≥1024×1536, 투명 배경 |
| `cutin.png` | 필살기 컷인, 가로 ≥1200×600 |
| `portrait.png` | 얼굴 아이콘 128×128 |
| `sprite.png` | 게임용 스프라이트 시트 (아래) |
원화 원본(작업 파일)은 `art-src/sky/illust/<id>/` 에 보관 (원화와 스프라이트는 별개 에셋).

## 스프라이트 시트 (`sprite.png`) — 10행 규격 (확정)
- 투명 PNG, 셀 **96×96**, **가로 4열 × 세로 10행 → 384×960** (할아버지 비행선은 셀 128×112 → 512×1120)
- 시점: **후방 3/4 탑다운 뒷모습, 화면 위쪽으로 비행** (선택 화면 원화와 다른 별도 에셋)
- 알파는 0/255만, 캐릭터는 셀 밖으로 잘리지 않게, 모든 프레임 같은 크기·같은 중심(몸통)
- 좌·우 기울기는 반전하지 않고 각각 제작 (소품 위치 고정: 고나는 별 가방이 항상 화면 오른쪽)

| 행 | 동작 | 열 0 | 열 1 | 열 2 | 열 3 | 재생 |
|---|---|---|---|---|---|---|
| 1 | `fly` 기본 비행 | 날개 중간 | 올림 | 중간 | 내림 | 반복 10fps |
| 2 | `bankL` 왼쪽 기울기 | 약(10~15°) | 약 | 강(약 25°+) | 강 | 8fps, 약→강 |
| 3 | `bankR` 오른쪽 기울기 | 약 | 약 | 강 | 강 | 8fps, 약→강 |
| 4 | `idle` 대기 | 부드러운 날갯짓 4프레임 | | | | 반복 6fps |
| 5 | `shoot` 일반 공격 | 준비 | 발사(위쪽) | 탄 상승 | 복귀 | 1회 12fps |
| 6 | `charge` 차지 | 오라 시작 → 점점 커짐 | | | 최대 | 반복 10fps |
| 7 | `bomb` 폭탄 | 시전 | 위쪽 섬광 | 최대 | 잔광 | 1회 10fps |
| 8 | `hurt` 피격 | 플래시 | 흔들림 | 붉은 틴트 | 복귀 | 1회 12fps |
| 9 | `defeat` 격파 | 균형 상실 | 기울어짐 | 추락(어지러움) | 낙하 | 1회 8fps |
| 10 | `win` 승리 | 상승 시작 | 날개 펼침 | 만세 | 반짝임 | 1회 8fps |

## 원화·컷인·아이콘 권장 크기
| 파일 | 권장 | 최소 | 비고 |
|---|---|---|---|
| `illust.png` 선택 화면 전신 | **1024×1536** (2:3 세로) | 1024×1536 이상, 세로형 | 투명 배경, 머리~발끝이 잘리지 않게 여백 포함 |
| `cutin.png` 필살기 컷인 | **1200×600** (2:1 가로) | 1200×600 이상, 가로형 | 상반신 위주, 속도선 배경은 별도 레이어 가능(투명 배경 권장) |
| `portrait.png` 얼굴 아이콘 | **256×256** (정사각) | 128×128 | 게임에서는 128로 축소해 사용, 얼굴 핵심 특징이 보이게 |

## 그 밖의 에셋 (이후 단계)
- 적/보스 시트: `public/assets/sky/v2/enemies/<id>.png` (규격은 별도 협의)
- 배경 레이어: `public/assets/sky/v2/bg/stage1-<layer>.png` (세로 반복 타일)
- 내부 해상도(270×480) 전환은 에셋 도착 후 함께 진행
