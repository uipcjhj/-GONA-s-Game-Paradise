# 03 · 스테이지 바이블 — 6 스테이지

공통
- 배경 4레이어: **L1 원경**(하늘·먼 풍경, 0.3배 스크롤) / **L2 중경**(건축·지형, 0.6배) / **L3 근경**(소품, 1.0배) / **L4 환경 효과**(실시간 입자).
- 스테이지 대표색이 서로 확실히 달라야 한다 (같은 그림에 색만 바꾸기 금지).
- **적 탄 가독성**: 적 탄은 배경과 반대 계열 + 흰 테두리. 배경 대표색과 같은 색의 적 탄 금지.
- 드롭 공통: P(파워업) = 주 보상, 폭탄 = 전략 보상, 메달 = 점수, 하트 = 희귀(스테이지 보급 횟수 제한).
- 구조: 오프닝 편대 → 패턴 변화 → 중간보스 → 강화 편대 → WARNING → 보스 3페이즈 → 응가 열차 한 칸 전진.

---

## STAGE 1 — 이유식 왕국
- **한 줄 콘셉트**: 처음 먹은 이유식이 반란을 일으킨 황금빛 숟가락 왕국
- **스토리 역할**: 튜토리얼 겸 세계관 소개. 막힘의 첫 원인 발견, 뽀글이·꾸덕이 첫 등장
- **대표색**: 황금 노을 #ffcf6a · 크림 #fff1cc · 연두 #9ed36a (적 탄: 진분홍·보라)
- **배경**: L1 황금 노을 하늘 + 멀리 거대 그릇 성 / L2 **이유식 강**과 쌀알 부유섬 / L3 거대 숟가락 기둥·그릇 건물·채소 섬 / L4 이유식 김(수증기), 떠다니는 쌀알
- **일반 몹**: 쌀알 병사(소형 편대) · 당근 전투기(돌진) · 브로콜리 박쥐(급강하) · 완두콩 포탑(고정 포대) · 감자 방패병(체력 높은 전진형) · 냄비 수송선(대형, P·폭탄 드롭)
- **중간보스**: **이유식 냄비 장군** — 뚜껑을 여닫으며 뜨거운 국물탄, 2페이즈
- **최종보스**: **거대 쌀떡 골렘** — 3페이즈 (아래 05 문서 상세)
- **드롭 연출**: P = 숟가락 모양 반짝이 / 메달 = 쌀알 금화 / 폭탄 = 작은 젖병 / 하트 = 딸기
- **탄막 분위기**: 느리고 둥근 탄, 부채꼴·원형 기본기 학습
- **대사**: 등장 — 쌀떡 골렘 "떡 하니 막아 주마!" / 격파 — "떡… 떡이 풀린다아…"

## STAGE 2 — 버섯가스 숲
- **한 줄 콘셉트**: 가스를 품은 발광 버섯들이 부풀어 길을 짓누르는 마법의 숲
- **스토리 역할**: 뽀글이·꾸덕이가 가스를 퍼뜨리는 현장, 코믹 비중 최대
- **대표색**: 청록 #2ec4a4 · 연보라 #b48ae8 · 발광 노랑 #f4ff7a (적 탄: 주황·빨강)
- **배경**: L1 보랏빛 숲 하늘 + 거대 버섯 실루엣 / L2 버섯 갓 지붕, 덩굴 다리 / L3 발광 버섯·움직이는 덩굴 / L4 발광 포자, 부푸는 가스 구름(시야 일부 가림 기믹)
- **일반 몹**: 방귀 버섯(죽을 때 가스 구름) · 포자 요정(나선 이동) · 가스 풍선(터지며 원형탄) · 덩굴 뱀(화면 가장자리) · 뿡 두꺼비(점프 돌진)
- **중간보스**: **방귀 풍선 비행정** — 풍선을 하나씩 터뜨리며 패턴 변화
- **최종보스**: **뿡뿡 버섯대왕** — 1) 갓 포자비 2) 갓이 갈라져 가스 분사 3) 대왕이 부풀어 화면 압박
- **드롭 연출**: 메달 = 포자 구슬, P = 빛나는 새싹
- **탄막 분위기**: 느리게 퍼지는 구름형 탄 + 빠른 직선 포자 혼합, 시야 가림 기믹
- **대사**: 등장 "뿡! 이 숲은 내 가스로 가득하다!" / 격파 "피시시시… 바람 빠졌다…"

## STAGE 3 — 소화 공장
- **한 줄 콘셉트**: 소화를 돕던 스팀펑크 공장이 폭주해 모든 컨베이어가 미쳐 돌아간다
- **스토리 역할**: 왕국의 기계 심장. 공장장이 꾸덕이에게 조종당한 사실 발견
- **대표색**: 황동 #d8a040 · 쇳빛 #5a6478 · 증기 흰 #eef2f6 · 경고 주황 #ff7a2e (적 탄: 청록·흰)
- **배경**: L1 굴뚝 실루엣·증기 하늘 / L2 거대 톱니바퀴·컨베이어(실제로 움직임) / L3 증기 파이프·리벳 판 / L4 증기 분출, 불티
- **일반 몹**: 톱니 쿠키(회전 돌진) · 감자 로봇(전진 사격) · 기계 당근(미사일) · 컨베이어 상자(라인 따라 이동) · 리벳 드론(편대)
- **중간보스**: **감자 로봇 비행정**
- **최종보스**: **철벽 믹서 3000** — 1) 칼날 회전 탄막 2) 뚜껑 열고 레이저 3) 과열 폭주(빠른 교차 나선)
- **드롭 연출**: 메달 = 볼트 동전, P = 기어
- **탄막 분위기**: 기계적·규칙적 패턴 (커튼·교차 레이저·개틀링), 리듬감
- **대사**: 등장 "갈아 버린다! 3000 RPM!" / 격파 "과열… 과열… 퓨즈 나감…"

## STAGE 4 — 수분의 바다
- **한 줄 콘셉트**: 물방울 도둑들이 물을 훔쳐 메말라 가는 발광 심해 유적
- **스토리 역할**: 엄마·아빠 능력의 테마 스테이지, 물이 돌아와야 다음 땅이 굳지 않는다
- **대표색**: 남색 #14306b · 청록 #3ed6e0 · 형광 분홍 #ff7ad9 (적 탄: 주황·노랑)
- **배경**: L1 깊은 남색 물빛 하늘 / L2 물방울 궁전·가라앉은 유적 / L3 발광 산호·해초 / L4 거품, 물결 굴절
- **일반 몹**: 물방울 도둑(훔친 물방울 들고 도주) · 젤리 해파리(촉수탄) · 거품 괴물(분열) · 랜턴 물고기(조준) · 산호 포탑
- **중간보스**: **물방울 도둑 대장**
- **최종보스**: **젤리 크라켄** — 1) 촉수 2개 2) 몸이 투명해지며 핵 노출 3) 거대화 물결 커튼
- **드롭 연출**: 메달 = 진주, P = 물방울 결정
- **탄막 분위기**: 물결처럼 휘는 탄, 거품 고리, 느린-빠른 혼합
- **대사**: 등장 "말랑말랑, 물은 다 내 거야!" / 격파 "흐물흐물… 물 돌려줄게…"

## STAGE 5 — 딱딱 응가 성문
- **한 줄 콘셉트**: 물을 잃고 굳어 버린 땅이 결정과 바위로 성벽을 쌓은 어두운 성채
- **스토리 역할**: 최종 결전 전 관문, 가족 대화로 "함께라면 뚫을 수 있다" 고조
- **대표색**: 회갈 #6b5a4e · 짙은 보라 #3a2350 · 결정 호박색 #e8a23c (적 탄: 청록·흰)
- **배경**: L1 붉은 노을 + 갈라진 대지 / L2 굳은 성벽·뒤틀린 탑 / L3 결정 기둥·바위 / L4 먼지, 균열 빛
- **일반 몹**: 돌멩이 병사 · 딱딱 쿠키 기사(방패 전진) · 변비 유령(관통 이동) · 결정 포탑 · 성벽 투석기
- **중간보스**: **변비 유령 대장**
- **최종보스**: **철벽 똥기사** — 1) 방패 돌진 2) 갑옷 균열 3) 갑옷 벗고 폭주 (실제 대변 모양 금지 — 굳은 바위 갑옷 기사로 표현)
- **드롭 연출**: 메달 = 호박 결정, P = 금빛 균열석
- **탄막 분위기**: 무겁고 빽빽, 벽형 탄막 + 빈틈 찾기
- **대사**: 등장 "이 성문은 아무도 못 지나간다, 딱!" / 격파 "부… 부서졌다…!"

## FINAL — 변비마왕성
- **한 줄 콘셉트**: 모든 막힘의 원흉이 사는, 폭풍에 휩싸인 거대한 막힌 성
- **스토리 역할**: 최종 결전, 뽀글이·꾸덕이 배신 개그 → 가족 6명 전원 협력으로 마지막 봉인 파괴
- **대표색**: 흑자주 #2a0f2e · 보라 번개 #b06cff · 금 테두리 #ffd34a (적 탄: 흰·하늘)
- **배경**: L1 폭풍 하늘·번개 / L2 막힌 거대 성문·성벽 / L3 왕좌로 가는 다리, 사슬 / L4 번개, 마법 폭풍
- **일반 몹**: 꽉막혀 근위대 · 흑기사 전투기 · 마왕 눈 포탑 · 바위 골렘 소형 · 뽀글이·꾸덕이(소형 보스급 이벤트)
- **중간보스**: **꽉막혀의 호위 기사**
- **최종보스**: **변비마왕 꽉막혀** — 1) 거대한 딱딱 갑옷 형태 2) 갑옷 파괴 폭주 형태 3) 거대 응가 운석 형태(동글한 운석 + 표정, 사실 묘사 금지) → 가족 협력 연출로 봉인 파괴
- **드롭 연출**: 메달 = 왕관 조각, P = 무지개 결정
- **탄막 분위기**: 지금까지 모든 패턴의 집대성 + 레이저
- **대사**: 등장 "흥, 누구도 이 길은 못 지나간다! 꽉!" / 2페이즈 "으아아, 막히고 막혔다!" / 3페이즈 가족 "마지막 봉인을 깨자!" / 격파 "뻥… 뚫…렸다…"
