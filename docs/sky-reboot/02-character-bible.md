## 고나 — 아기 익룡 영웅
- **성격**: 겁 없음 · 호기심 · 먹는 걸 좋아함 · 끝까지 포기 안 함 ("아부부!")
- **실루엣**: 둥근 머리 + 큰 후드, 양옆으로 펼친 주황 날개, 뒤로 휘날리는 빨간 스카프 — 작은 몸에 큰 날개의 삼각형
- **얼굴/헤어**: 작은 얼굴, 큰 눈, **말린 갈색 머리카락 한 가닥**이 후드 밖으로
- **의상**: 연두색 익룡 후드 + **노란 볏**, 주황 날개, 빨간 스카프, 고글(비행용)
- **무기**: 입김/날개 에너지 (별사탕 모양 에너지탄 — 기존 유지)
- **평타**: 직선 에너지탄, 파워 1~4단계로 갈래·굵기 증가
- **차지샷**: 초강력 응애파 (관통 충격파)
- **근접**: 익룡 날개 돌진
- **폭탄(=고나 필살)**: 황금 익룡의 포효 — 화면 탄 소거 + 광역 피해
- **리부트 변경**: 외형 유지. 소화왕국풍 소품만 추가 가능 (예: 숟가락 모양 고글 끈). 전투 스프라이트는 기존 승인본 재사용 가능.

## 엄마 — 목욕의 물마법사
- **성격**: 다정함 · 걱정 많음 · 고나 일에는 단호함
- **실루엣**: 펄럭이는 목욕가운 자락 + 한쪽으로 늘어진 말꼬리, 손에 든 스펀지 지팡이
- **얼굴/헤어**: **넓은 이마**, 한쪽으로 묶어 **말린 말꼬리 머리** (기존 그대로)
- **의상**: 흰 목욕가운(분홍 허리띠), 비눗방울 장식, 수건 망토
- **무기**: 거품 스펀지 지팡이
- **평타**: 전방 부채꼴 물방울 5발 (유도 없음)
- **차지샷**: 응축 물줄기 (전방 집중 관통)
- **근접**: 물보라 휘두르기
- **필살기**: **「쏴아아아! 목욕 폭포」** — 화면 위에서 물줄기가 넓게 쏟아짐 (광역, 보스엔 절반 피해)
- **대표색**: 하늘색 · 흰색 · 분홍 포인트

## 아빠 — 급수 소방 전사
- **성격**: 듬직함 · 열혈 · 약간 허세 ("막힌 길은 내가 뚫어 주지!")
- **실루엣**: 어깨에 멘 큰 황동 물대포 → 한쪽이 무거운 비대칭 실루엣
- **얼굴/헤어**: **갈색 곱슬머리**, **외꺼풀이지만 부리부리한 눈**, 강한 눈빛
- **의상**: 판타지 아케이드풍 소방복 (빨강+노랑 반사띠), 황동 헬멧, 물통 배낭
- **무기**: 황동 물대포
- **평타**: 굵은 직선 물탄 (좁고 강함)
- **차지샷**: 고압 물줄기 관통 (빨리 참)
- **근접**: 물대포 충격파 (최고 근접 피해 — 위험 감수형 화력)
- **필살기**: **「수분충전! 급수 브레이커」** — 물을 꿀꺽 마신 뒤 굵은 직선 수압 빔. **적탄 삭제 없음**
- **대표색**: 소방 빨강 · 황동 · 물빛

## 이모 — 프룬의 보랏빛 요정
- **성격**: 시크 · 장난기 · 고나 바보 ("좋아, 출격하자!")
- **실루엣**: 엄마와 닮은 체형 + 더 날렵한 포즈, 작은 요정 날개, 어깨에 걸친 프룬 캐논
- **얼굴/헤어**: 엄마를 닮은 얼굴, **낮은 쪽머리**, **좁은 검은 선글라스(제니 스타일)**
- **의상**: 힙한 보라 재킷 + 과일·채소 장식(프룬 브로치, 잎사귀 귀걸이), 반투명 요정 날개
- **무기**: 프룬 캐논
- **평타**: 빠른 직선 프룬 에너지탄 3발 (유도 없음)
- **차지샷**: 관통 프룬 캐논
- **근접**: 개머리판 보라 폭발
- **필살기**: **「프룬주스 퍼플 버스트」** — 짧고 화려한 보라 폭발 (화력은 낮게)
- **대표색**: 보라 · 연보라 · 과일 초록

## 할머니 — 약손 치유사
- **성격**: 늘 방글방글 · 화나면 무서움(코믹) · 손주 사랑 최고
- **실루엣**: 작고 동그란 체형, 커다란 약솥/약병, 머리 위 쪽진 머리
- **얼굴/헤어**: **방글할매** — 항상 웃는 눈, 동그란 볼 (필살기 때만 화난 표정 1장)
- **의상**: 따뜻한 한복풍 앞치마 + 약초 주머니
- **무기**: 연금 약솥 / 포션 병
- **평타**: 포션 병 투척 (명중 시 작은 폭발)
- **차지샷**: 연금 폭발 플라스크 (범위)
- **근접**: 약솥 휘두르기
- **필살기**: **「현이 배는 똥배! 할미 손은 약손!」** — 화난 얼굴 → 불꽃 + 하트 → 체력 1칸 회복(최대 체력 초과 없음, 별도 무적 없음)
- **대표색**: 따뜻한 주황 · 금 · 분홍 하트

## 할아버지 — 유해균 방패 수호자
- **성격**: 근엄 · 능청 · 가끔 방귀 개그(방구할배)
- **실루엣**: **몸보다 큰 둥근 방패**가 실루엣의 중심, 갑옷은 가볍게
- **얼굴/헤어**: **흰머리**, 근엄한 눈썹, 코믹한 미소
- **의상**: 가벼운 은빛 흉갑 + 남색 망토, 방패에 유산균 문양
- **무기**: 유산균 문양 거대 방패 + 짧은 창
- **평타**: 방패에서 나가는 직선 충격파 (창)
- **차지샷**: 방패 파동 (근거리 탄 소거 + 피해)
- **근접**: 방패 밀치기
- **필살기**: **「나쁜 세균은 못 지나간다!」** — 짧은 시간 방패 보호막 (범위 표시, 지속 시간 제한)
- **대표색**: 은 · 남색 · 유산균 초록

## 삼촌 — 유산균 소환사
- **성격**: 괴짜 · 수다쟁이 · 발명 덕후
- **실루엣**: 헝클어진 머리 + 둥근 안경 + 흰 실험복 자락, 손에 든 빛나는 유산균 병
- **얼굴/헤어**: **기존 안경 · 헝클어진 머리 그대로**
- **의상**: 실험복 + 공구 벨트, 병 홀더
- **무기**: 유산균 병 / 소형 소환 장치
- **평타**: 직선 에너지탄 2발 (기존 구조)
- **차지샷**: 폭발 유산균 캡슐 (명중 시 주변 피해)
- **근접**: 유산균 충격파
- **필살기**: **「출동! 유산균 특공대!」** — 귀여운 유산균 3마리가 고나 주변을 돌며 3초간 공격 (개체 수·시간 제한)
- **유산균 3종**: 동글이(원형) · 캡슐이(알약형) · 꼬불이(나선형) — 각자 표정·눈 있음, 기계 외형 금지
- **대표색**: 청록 · 흰색 · 노랑
