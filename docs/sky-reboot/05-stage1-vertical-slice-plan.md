# 05 · Stage 1 수직 슬라이스 계획 — 이유식 왕국

목표: **아트 방향 확정 + 룩앤필 검증**. 타이틀 → 오프닝 → 선택 → Stage 1 (편대 → 중간보스 → 보스 3페이즈) → 클리어까지, 응가 테마의 "최종 품질 한 판"을 만든다. 2~6 스테이지는 이 판이 승인된 뒤에.

## 1. 범위
| 포함 | 제외 |
|---|---|
| 타이틀·로고, 오프닝(핵심 컷), 선택화면 7명, 대화창 | 엔딩 컷신 (P2) |
| Stage 1 배경 4레이어, 일반 몹 5~6종, 중간보스, 보스 3페이즈 | Stage 2~6 그래픽 |
| 가족 6명 필살기 컷인 + 응가 테마 공격 이펙트 | 새 음악 (기존 BGM 재사용) |
| Stage 1 오프닝/중간보스/보스전/클리어 대사 | 밸런스 대규모 재조정 (이미 1차 완료) |

## 2. 보스 설계 — 거대 쌀떡 골렘 (3페이즈)
| 페이즈 | 외형 | 패턴 (기존 엔진 공격 조합) | 전환 연출 |
|---|---|---|---|
| 1 | 하얀 쌀떡 몸 + 양어깨 그릇 포탑 2개 | 부채꼴 쌀알탄 · 조준 연사 · 포탑 원형탄 | 포탑 파괴 시 그릇 깨짐 |
| 2 | 표면이 갈라져 붉은 소스가 흐름 | 떡 늘이기 돌진(경고선) · 쌀알비 · 2갈래 나선 | 탄 소거 + "쫀득!" 외침 |
| 3 | 굳어 바위처럼 변하고 가운데 노란 쌀알 핵 노출 | 교차 나선 · 조준 레이저 · 고리 펄스 (핵이 약점) | 화면 흔들림 + 격파 2프레임 |

중간보스 **이유식 냄비 장군**: 1) 뚜껑 닫힘 — 국물 원형탄 2) 뚜껑 열림 — 김 커튼 + 국자 조준탄. 48초 후 도주(기존 규칙).

## 3. 대사 (짧게 — 한 줄 40자 안팎)
- **스테이지 시작**: 고나 "아부부!" · 선택 동료 1줄 (엄마 "우리 고나 편하게 해 줄게!" · 아빠 "막힌 길은 내가 뚫는다!" · 이모 "좋아, 출격하자!" · 할머니 "할미가 다 고쳐 주마~" · 할아버지 "고나야, 방패 뒤로!" · 삼촌 "유산균 출동 준비 완료!")
- **중간보스 전**: 뽀글이 "여긴 우리 꾸덕꾸덕 길이야!" / 꾸덕이 "냄비 장군님, 부탁해요!"
- **중간보스**: "뜨끈한 국물 맛 좀 봐라!" → 격파 "끓어 넘친다아~"
- **보스 등장**: "떡 하니 막아 주마!"
- **보스 2페이즈**: "쫀득쫀득! 아직이다!"
- **보스 격파**: "떡… 떡이 풀린다아…"
- **클리어**: 응가 열차 "뿌우~!" 한 칸 전진 · 고나 "다음 길로 가자고나!"

## 4. 구현 순서
1. **아트 방향 확정** (이미지 도구 필요)
   1. 고나 + 엄마 1명으로 "원화 1장 + 비행 스프라이트 1장 + 컷인 1장" 시안 → 승인
   2. Stage 1 배경 L1 + 쌀알 병사 1종 + 쌀떡 골렘 1페이즈 시안 → 같은 화면에 배치한 목업 승인
2. 승인 기준으로 나머지 P0 에셋 일괄 제작 (04 문서 P0 목록)
3. Claude 적용: 트리밍·축소·시트 배치 → `assets.ts` 에 `v3-poop` 경로 (케이크 v2 그대로) → 테마 팩에서만 사용
4. 엔진 연결: Stage 1 적 이름·외형 교체, 보스 3페이즈 외형 전환, 대화창(신규 UI 컴포넌트, 응가 테마 전용)
5. 검수: 393×636 · 390×844 스크린샷, 전후 비교, 탄 가독성, 콘솔 오류, 60fps (CPU 저속 측정)
6. `/GoNa/sky-poop-test/` 배포 — **Pages 출처가 GitHub Actions 로 바뀐 뒤에만**
