# 11 · iPhone Safari 직접 확인 체크리스트 (응가 테스트 빌드)

자동 검수(크롬 · iPhone 화면 크기 5종 · 터치 흉내)로 확인한 것과, **실제 iPhone 에서만 알 수 있는 것**을 나눔.

## A. 자동으로 확인한 것 (tools/sky-mobile-check.cjs · tools/sky-story-check.cjs)
- 화면 크기 375×667 · 393×636(인앱) · 390×844 · 393×852 · 430×932: 대화창·무전창·필살/폭탄/일시정지/SKIP·엔딩 버튼이 모두 화면 안, 가로 스크롤 없음, 엔딩 그림 잘림 없음, 콘솔 오류·404 없음
- 스테이지 1→6→엔딩→크레딧 자동 진행, 스테이지마다 대화 10개 열림, 정지 대화·무전창 대사가 정해진 순서대로 표시
- 정지 대화 중 전투 시간·탄·적 정지, 끝나면 재개 · 무전창 중에는 전투 계속

## B. iPhone 에서 직접 확인할 것
### 소리 (자동 검수로 확인 불가)
- [ ] 타이틀에서 화면을 한 번 터치하면 음악이 나옴 (무음 모드 스위치가 켜져 있으면 안 나오는 것이 iOS 기본 — 끄고 확인)
- [ ] 대화창 글자 찍히는 소리 · 다음 줄 넘김 소리가 너무 크거나 시끄럽지 않은지
- [ ] 엔딩: 열차 출발음 → 하얀 화면 전환음 → 힘주기 효과음 → "뿡!" 효과음 → 응가 성공 효과음 → 가족 반응 소리 → 포옹 회복음 → 엔딩 음악
- [ ] 다른 앱 갔다 와도(홈 화면 → 복귀) 소리가 다시 나는지

### 조작감
- [ ] 손가락으로 끌어서 고나가 부드럽게 따라오는지 (손가락에 가려지지 않는지)
- [ ] 차지 길게 누르기 · 필살 · 폭탄 · 근접 버튼이 잘 눌리는지 (화면 확대·텍스트 선택·복사 메뉴가 뜨지 않는지)
- [ ] 무전창이 떠 있을 때도 전투 조작이 그대로 되는지 (무전창은 터치를 막지 않아야 함)
- [ ] 보스 대화창: 터치 한 번 → 글자 전부 보이기, 한 번 더 → 다음 줄 · SKIP 이 한 번에 끝나는지
- [ ] 대화가 끝난 직후 바로 맞지 않는지 (0.8초 무적)

### 화면
- [ ] 노치·다이내믹 아일랜드·홈 막대에 HUD/버튼이 가리지 않는지 (세로 모드)
- [ ] Safari 주소창이 줄었다 커졌다 할 때 화면이 튀지 않는지 · 인앱 브라우저(카톡 등)에서도 393×636 처럼 잘 보이는지
- [ ] STAGE 1 배경·적·보스가 흐리지 않고 또렷한지 (픽셀이 뭉개지지 않는지)
- [ ] 쌀떡 골렘 2페이즈 금빛 균열이 피·응가처럼 보이지 않는지
- [ ] STAGE 2~6 화면 아래에 '임시 그래픽' 표시가 보이는지

### 대사 · 템포 · 난이도
- [ ] 정지 대화는 보스 등장·격파(+FINAL 가족 협력)에만 나오는지, 너무 길지 않은지
- [ ] 무전창(위쪽 작은 창) 글이 읽을 시간이 충분한지 · 전투를 가리지 않는지
- [ ] 뽀글이·꾸덕이 등장이 스테이지마다 다르게 느껴지는지 (방향 · 장난 · 도망 방식)
- [ ] NORMAL 난이도로 STAGE 1 을 몇 번 만에 깨는지 · 너무 쉽거나 어렵지 않은지

### 엔딩
- [ ] 약 39초 자동 진행 — 너무 길거나 짧지 않은지, 터치하면 빨리 넘어가는지, '엔딩 건너뛰기' 동작
- [ ] 가족이 말할 때 그 사람 그림이 커지는지 · 잘리지 않는지
- [ ] 크레딧에서 '타이틀로' 가 잘 동작하는지

## C. 테스트 빌드 여는 법
- 미리보기 링크(비공개 아티팩트)를 iPhone Safari 에서 열기
- 주소 끝에 `#dev` 를 붙이면 (로컬 서버는 `?dev` 도 됨): 선택 화면에서 STAGE 1~6 바로 시작 · 타이틀의 '엔딩' 버튼으로 엔딩만 보기
