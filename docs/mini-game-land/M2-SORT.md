# M2 — 고나의 편가르기 대소동 (`sort`)

구현: `src/mini-game-land/games/sort/` · 규칙·판정은 전부 `logic.ts`(순수 함수), 화면은 `View.tsx`.
M1 공통 시스템(타이머·점수·콤보·목숨·일시정지·결과·기록)을 그대로 쓰며 자유 플레이/랜덤 챌린지가 **같은 모듈**을 마운트합니다.

## 게임 방식
친구 카드(색 · 표정 · 특징 3축)가 한 장씩 나오고, 규칙에 맞는 분류함으로 보냅니다.

| 조작 (모두 터치만으로 가능) | 설명 |
| --- | --- |
| 카드 스와이프 | 카드를 손가락으로 끌어 ◀ ▶ 로 밀기(36px 이상). 3분류에서는 ▲ 위로 밀면 가운데. 끄는 동안 해당 분류함이 노랗게 강조되고, 짧게 밀면 원위치 |
| 분류함 탭 | 화면 아래 큰 분류함(높이 72px 이상)을 탭 — 스와이프와 동일하게 처리 |
| (보조) 키보드 ← → ↑ | 개발·접근성용 |

## 규칙 확장 (난이도)
| 레벨 | 규칙 종류 | 카드 축 | 목표 카드 | 함정 카드 | 비고 |
| --- | --- | --- | --- | --- | --- |
| 1 | 단일 (예: 빨강이면 왼쪽) | 색 | 10 | 0% | |
| 2 | 단일 | 색·표정 | 11 | 0% | |
| 3 | 단일 | 색·표정·특징 | 12 | 0% | |
| 4 | **복합**: 그리고 (빨강 + 안경) | 전체 | 12 | 30% | 하나만 맞으면 오른쪽 = 함정 |
| 5 | 그리고 / 또는 | 전체 | 13 | 40% | |
| 6 | + **제외** (빨강, 화난 얼굴 제외) | 전체 | 13 | 50% | 제외 특징이 있으면 오른쪽 = 함정 |
| 7 | 제외 / **3분류** (빨강·파랑·나머지) | 전체 | 14 | 60% | 나머지는 위로 |
| 8~10 | 위 전부 + **규칙 반전** 1·2·3회 | 전체 | 14→16 | 60% | 반전 카드에서 0.7초 예고, 좌우가 뒤바뀜 |

- 라운드마다 시드로 규칙이 새로 뽑힘. 정답은 항상 하나, 한쪽 쏠림 방지(같은 방향 연속 2분류 3장·3분류 2장 이하).
- 시작은 쉬운 분류(색)부터 → 표정 → 특징 → 복합 → 제외 → 3분류 → 반전 순으로 확장.

## 승리 · 실패
- **클리어**: 목표 카드를 모두 처리하고 실수가 3번 미만.
- **실패**: 실수 3번(즉시) 또는 제한시간 종료. 제한시간 = 목표 × (카드당 3.2초 → 2.0초) + 4초, 두 모드 공통.

## 점수
- 정답 +100, **0.8초 이내 판단 +50**(잠금·예고 시간 제외하고 측정).
- **연속 정답 콤보**: 배수 1 + 0.1×연속(상한 ×2), 오답 시 리셋. HUD 에 COMBO ×N 표시.
- 클리어 보너스 +300(콤보 배수 없음) + 공통 시간 보너스(남은 초×10). 챌린지는 라운드 배율 적용, 실패 라운드 0점.

## 오답 피드백
오답이면 상단에 설명이 뜹니다: `파랑 ○ · 안경 × → 정답은 오른쪽` (반전 중이면 `(반전 중!)` 추가). 심판 고나가 좌우로 흔들림.
오답 직후 0.35초는 입력 잠금(연타로 실수가 연쇄되는 것 방지).

## 현재 화면의 임시 표현 (최종 아님)
카드(색 블록·이모티콘 표정·모자/리본/안경 도형)와 분류함은 **기능 확인용 임시 도형**입니다. 심판 고나는 승인된 `gona.png` 를 ×2 정수 배율로 사용.

# 최종 에셋 제안 (제작 전 — 승인 후 단계적으로)

공통 규격: 투명 PNG · 1도트 = 논리 1px(정수 배율로만 확대) · `gona.png`(27×34)와 같은 팔레트·선 굵기(어두운 외곽선 1도트) · `image-rendering: pixelated`.

| # | 에셋 | 규격 | 수량 | 비고 |
| --- | --- | --- | --- | --- |
| S1 | 친구 몸체 | 32×32, 색 4종(빨강·파랑·초록·노랑) | 4 | 고나처럼 동그란 공룡 슈트 친구. 색 구분이 흑백에서도 보이도록 무늬 차이 권장 |
| S2 | 표정 오버레이 | 32×32, 4종(웃음·울음·화남·졸림) | 4 | 몸체 위에 겹침. 작은 이목구비 스타일 유지 |
| S3 | 특징 오버레이 | 32×32, 3종(리본·모자·안경) | 3 | 머리·눈 위치 고정 → 어떤 몸체/표정과도 조합 가능 (4×4×4=64 조합을 12장으로) |
| S4 | 분류함 | 56×40, 좌/우/가운데 3종 + 눌림 상태 | 6 | 바구니·상자 느낌. 라벨은 텍스트로 별도 표시 |
| S5 | 심판 고나 | 27×34, 3프레임(대기·정답 기뻐함·오답 어지러움) | 3 | 대기 프레임은 기존 `gona.png` 재사용 |
| S6 | 반전 예고 | 64×24 배너 + 화살표 아이콘 16×16 2종 | 3 | ⇄ 연출용 |
| S7 | 배경 | 180×320 1장 (심판석·무대 느낌) | 1 | 가장자리 타일 반복 가능하게 |
| S8 | 효과 | 16×16 반짝이/오답 ✕ 4프레임 | 8 | 정답 반짝, 오답 흔들림 |

합계 약 32장. 우선순위: **S1–S3(카드) → S4(분류함) → S5(심판) → 나머지**. 스프라이트 시트로 묶어 `public/assets/mgl/sort/` 에 둘 예정.
