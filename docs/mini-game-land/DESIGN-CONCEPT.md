## 1. 한 줄 콘셉트
**"월드맵의 ‘미니게임천국’ 섬 안으로 들어가기."**
월드맵 오른쪽 아래 섬에는 이미 줄무늬 텐트, 게임 패드가 달린 오락실 건물, 대관람차, 풍선, 웃는 젤리 친구들(파랑·분홍·노랑)이 있습니다. Mini Game Land 는 그 섬을 확대한 **작은 놀이공원 + 오락실**이고, 화면 요소를 모두 그 안의 물건으로 만듭니다. 그래서 게임천국 → 섬 터치 → 게임 진입이 하나의 세계로 이어집니다.

| 화면 요소 | 놀이공원 속 모습 |
| --- | --- |
| 배경 | 섬 위 하늘 + 줄무늬 텐트·대관람차가 멀리 보이는 잔디 광장 (게임별로 부스 안쪽 장면) |
| 버튼 | 나무 판자 + 줄무늬 천 차양이 달린 매표 창구 느낌의 도톰한 버튼 |
| 패널·팝업 | 크림색 티켓/나무 간판, 모서리를 도트로 깎은 9-slice |
| 점수판 | 오락실 기계 위 **전광판**(노란 전구 테두리, 숫자는 도트 폰트) |
| 시간 | 줄무늬 리본/깃발 줄이 줄어드는 막대 (5초 이하 빨강으로 깜빡) |
| 목숨 | **풍선**(월드맵에 있음). 하나 터지면 하나 줄어듦, 보너스 목숨은 새 풍선이 떠오름 |
| 결과 화면 | 상장/티켓 + 폭죽·별, 신기록은 금색 도장 |
| 심판·마스코트 | 고나(심판 호루라기·응원·어지러움 포즈) |

## 2. 아트 디렉션 (월드맵·고나와 통일)
- **굵고 선명한 도트**, 안티앨리어싱·흐린 확대 금지, 정수 배율만. 순수 #fff/#000·형광색 지양, 밝지만 살짝 바랜 색.
- **도트 밀도 정합**: 캐릭터·큰 소품은 **1도트 = 4px**(게임천국의 고나 ×4와 동일), UI 프레임·아이콘은 **1도트 = 2px**. 글자는 지금처럼 Galmuri(OFL).
- **윤곽선**: 캐릭터·소품은 고나와 같은 짙은 갈색 `#3b2419`, UI 프레임은 월드맵 바다 윤곽의 네이비 `#173073`. 외곽선 1도트.
- **그림자**: 번짐 없는 딱딱한 1~2도트 오프셋. 그라데이션·둥근 모서리 카드·머티리얼 느낌 금지.
- **금지 재확인**: 승인된 월드맵·고나 스프라이트 재제작/왜곡 없음. 새 그림은 모두 PNG 에셋(CSS/Canvas 흉내 금지).

## 3. 화면별 제안
1. **홈**: 놀이공원 입구 아치(로고 `GONA's Mini Game Land`) + 고나가 손 흔듦 + 매표소 버튼 3개(자유 플레이/랜덤 챌린지/내 기록). 하단 `← 게임천국`(월드맵 아이콘)·소리.
2. **자유 플레이 선택**: 부스 3개가 나란한 거리 — 각 게임이 줄무늬 천막 부스(간판 아이콘 + 최고 기록 별). 잠긴 부스는 천이 닫혀 있음.
3. **플레이(HUD)**: 위에 전광판(점수) + 줄무늬 시간 리본 + 풍선 목숨 + 일시정지 아이콘. 게임판은 게임마다 다른 부스 안쪽.
4. **일시정지·결과**: 티켓 모양 팝업, CLEAR!/MISS/TIME UP 은 간판 배너, NEW RECORD 는 금색 도장+별.
5. **편가르기**: 심판석(고나 + 나무 규칙 간판) / 가운데 무대에 젤리 친구 카드 / 아래 줄무늬 바구니 분류함 2~3개(좌·우·가운데 아이콘), 반전 시 간판이 뒤집히는 연출.

## 6. 제작·검수 방식 제안
1. **시안 1장 승인**: 홈 + 편가르기 플레이 화면을 393×636 기준으로 제안(이미지 시안) → 방향 확정.
2. **P0 에셋 제작** → `skin/pixel/` 스킨으로 슬롯 교체 → 전후 비교 스크린샷(393×636·390×844) → 승인.
3. 이후 P1, 그리고 M3·M4 게임이 추가될 때 그 게임 슬롯용 에셋을 같은 방식으로.
- **제작 수단은 결정이 필요합니다**: (a) 직접/외부 제작 파일 전달, (b) 연결된 이미지 생성 도구로 시안·에셋 생성 후 PIL 로 팔레트·정수 배율 후처리(크레딧 발생 가능 — 명시 승인 시에만), (c) 시안만 생성하고 나머지는 직접 제작.
- 임시 스킨(`temp`)과 점검 스킨(`wireframe`)은 개발용으로 남기되 기본 스킨은 최종 스킨으로 교체합니다.
