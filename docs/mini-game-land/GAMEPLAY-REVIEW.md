# Mini Game Land 게임성 재검토 · 신규 게임(M5 후보) 선정

> **자동 테스트 통과 ≠ 재미.** 아래 수치는 봇·코드로 잴 수 있는 *템포*(시스템이 강제하는 대기)뿐이다. "재미있는가 / 다시 하고 싶은가"는 사람 플레이 테스트로만 판단할 수 있다(§3).
> 측정 도구: `tools/fun-metrics.cjs` (실제 터치 봇, 393×636) · 결과 `metrics-before.json` / `metrics-after.json`

## 1. 기존 3종 분석
| | 편가르기 (sort) | 아슬아슬 탑 (tower) | 장난감방 (toyroom) |
|---|---|---|---|
| 핵심 재미 | 규칙을 읽고 빠르게 판단(반응+판단), 반전·함정 | 물리 손맛, 아슬아슬함, 쌓아 올리는 성취 | 순서·공간 퍼즐, 한 수로 두 곳 정리(연쇄) |
| 한 판 길이(설계) | 10~16장 × 1~3초 ≈ 20~45초 | 조각 10~17개 × 2~4초 ≈ 30~60초 | 이동 8~14번, 생각 시간 포함 30~90초 |
| 입력 빈도 | 높음(카드마다 1회, 초당 ~0.5~1) | 중간(조각마다 드래그 1회 + 대기) | 낮음(생각 → 탭 2번) |
| 시스템 대기(개선 전) | 입력 잠금 거의 없음(오답 0.35초만) | **조각마다 ~0.7초**(낙하+가라앉기) + 성공 후 2.8초 | **이동마다 0.57초** 연출 잠금 |
| 실패 원인 | 실수 3번 / 시간 | 떨어뜨림 한도 / 조각 소진 / 시간 | 이동 소진 / 막힘 |
| 반복 동기 | 점수·콤보·레벨 해금 | 레벨·완벽 보너스 | 별(par)·레벨 |
| 우려(사람 테스트 필요) | 규칙 문장 읽기 부담(L6+ 복합 규칙) | 정착 대기가 길게 느껴지는지, 바람 체감 | 첫 판에서 '빼면 양옆이 붙는다' 규칙 이해 |

## 3. 사람 플레이 테스트가 꼭 필요한 것
1. 각 게임 첫 판: 설명 없이 3초 안에 무엇을 할지 아는가 (특히 장난감방)
2. 한 판 끝나고 "한 판 더"를 누르는가 (반복 동기) — 결과 화면의 다음 행동 선택 비율
3. 탑의 정착 대기·편가르기 복합 규칙이 답답하거나 어려운가
4. 간식 받아라: 손가락이 고나를 가리는지, 고추를 피하는 게 공정하게 느껴지는지
5. 레벨 곡선: 봇 성공률은 참고값 — 실제 사람 성공률로 `tuning.ts` 조정

## 5. MVP: 고나의 간식 받아라! (`games/catch`)
- 규칙: 손가락 x = 고나 위치. 간식(딸기·쿠키·사탕, 별=보너스)은 받고 🌶 고추는 피함. 놓친 간식·받은 고추 = 실수, 실수 한도면 실패, 목표 개수면 성공.
- 레벨(임시값, `logic.ts TUNING`): L1 고추 없음·느림(목표 18) → L10 빠름·간격 짧음·고추 32%·동시 낙하·흔들림(목표 36). 제한시간 = 목표 기준 + 10초 → 한 판 약 20~45초.
- 공정성: 동시 낙하는 두 번째를 살짝 늦게, 고추는 바구니 정위에 바로 생성하지 않음, 빠른 낙하도 판정 누락 없음(선분 판정).
- 연결: 자유 플레이·랜덤 챌린지 자동 포함, Mini Game Land 기록, 게임천국 결과·XP·코인, 업적 `간식 대장`, 도감 `간식 받아라`, 이 기기 랭킹 '간식' 탭.
- 슬롯: `Backdrop · Catcher · Item · Meter · Pop` (temp·pixel 스킨 모두 구현, 그림은 코드 도트 임시 디자인)
- 측정: 사람형 봇(반응 0.25초·손 속도 제한) 성공률 L1 ≥ 80%, L10 은 그보다 낮음 / 완벽 봇은 레벨당 20판 중 18판↑ 클리어(풀 수 있음) / 아무것도 안 하면 실패.

## 6. 다음 게임 추천 순위
1. **줄넘기 타이밍** — 한 번 탭, 리듬감, 개발 비용 최저. 액션 템포를 이어 줌
2. **고나 찾기** — 관찰형, 기존 친구 스프라이트 재사용 가능
3. **짝 맞추기 기억** — 연령층 넓음, 휴식형
4. 징검다리 점프 — 손맛은 좋지만 조작 학습 비용

## 7. M6 고나의 폴짝폴짝 줄넘기 (`games/jump`)
- 규칙: 화면 어디든 탭 = 점프(공중 0.44초). 줄이 발밑을 지나는 순간 공중이면 성공 — 점프 한가운데 ±70ms 는 **PERFECT**(150), 그 밖의 공중은 **GOOD**(100), 땅이면 **MISS**. 실수 3번 실패, 목표 횟수 성공.
- 공정성: 공중에서 다시 탭은 무시(연타 방지), **입력 지연 보정 35ms**(임시값 — 실기기 측정 필요), 모든 바퀴는 공중 시간 + 0.15초 이상(테스트로 보장), 첫 통과는 시작 1초 뒤(박자 보고 시작).
- 변화: 판 안에서 점점 빨라짐(L1 1.15→1.05초 … L10 0.83→0.65초), L4~ 박자 변화(빠름·느림, **"빨라져요!" 예고**), L6~ 두 번 연속 빠른 줄("두 번!").
- 한 판: L1 18회 ≈ 19초(실제 탭 E2E), L10 36회 ≈ 30초. 제한시간 ≤ 60초.

## 8. M7 고나의 가짜 친구 찾기 (`games/spot`)
- 규칙: 똑같은 친구들 중 **딱 한 곳**이 다른 가짜를 탭. 오답 = 실수(3번 실패, 콤보 끊김, 칸 흔들림 + "진짜 친구예요!"), 1.5초 안에 찾으면 +50.
- 편가르기와의 차이: 편가르기는 '규칙 문장을 읽고 한 장씩 분류', 이건 '여러 명을 훑어 차이를 찾는' 시각 탐색.
- 변화: 친구 수 4 → 30, 차이 축 색(쉬움) → 소품 → 표정 → **좌우 반전**(리본 위치로만 보임, 가장 어려움), L8~ 자리 섞기(3~4초마다 가짜가 이동).
- 한 판: 판 10~14개. 봇(0.45초/판)은 L1 6초 — **사람은 판당 1.5~3초로 예상 → 약 20~40초(실측 필요)**.
