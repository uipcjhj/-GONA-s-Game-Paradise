## 구도 요점
- **색**: 게임판은 크림·민트·코랄·나무색 중심(따뜻함), 파랑은 포인트(홈 하늘, 방향 배지, 일시정지 외 강조)로만. 윤곽선은 UI=네이비 `#173073`, 캐릭터·소품=고나 브라운 `#3b2419`.
- **도트**: 고나 ×4(홈, 108×136) / 편가르기 심판은 가독성 때문에 ×3(81×102)로 조정, 친구 24×24 ×4=96px, UI 1도트=2px, 모서리는 둥글림 대신 도트로 깎기.
- **터치 영역**: 분류함 높이 약 104~118px(모든 버튼 44px 이상), 카드 영역은 화면 중앙 가장 넓게. 3분류에서 ▲ 위로 밀기 안내가 게임판 위쪽에 표시.
- **정보 위계**: 점수(LED)·콤보·시간·목숨(풍선)을 한 줄 전광판에 → 규칙 간판(심판 고나) → 진행/실수 → 게임판 → 분류함.
- **분위기**: 유치한 도형 대신 간판 전구·나무 판자·줄무늬 차양·전광판으로 레트로 오락실/놀이공원 톤. (스타듀밸리식 정교함을 위해 최종 에셋에는 디더링·재질 하이라이트·작은 소품 디테일 추가 예정)

## 최종 에셋 제작 방식 — 선택지와 비용 (결정 필요)
현재 잔액 확인: **287 크레딧 (Pro 플랜)**. 모델 조회에서 **이미지 1장당 크레딧 단가는 확인되지 않아** 정확한 비용을 추정하지 않았습니다.

| 방식 | 설명 | 비용 | 장단점 |
| --- | --- | --- | --- |
| **(a) 코드 제작(PIL)** — 지금 청사진과 같은 방식 | 도트 격자 그대로 직접 그림. 팔레트·정수 배율 100% 보장 | 0 크레딧 | 정확·일관·수정 쉬움. 다만 손그림 수준의 '스타듀밸리급' 표현력은 한계 |
| **(b) 이미지 생성 도구 + 후처리** | 생성 → 격자 정렬(축소)·팔레트 양자화 → 스프라이트로 정리 | 크레딧 발생(단가 미확인) | 분위기·디테일 우수. 생성형은 도트 격자가 어긋나고 시트 일관성이 약해 후처리 비용이 큼 |
| **(c) 하이브리드 (권장)** | 핵심 분위기 시안 1~2장만 생성(방향 확정용) → 실제 에셋은 (a)로 격자에 맞춰 제작 | 소량 | 방향 확인은 풍부하게, 최종 품질·일관성은 코드로 보장 |
| (d) 직접/외부 도트 작가 | 사용자 또는 외주가 제작한 파일을 받아 스킨에 적용 | 외부 | 최고 품질 가능, 일정은 외부 의존 |

**(c)·(b)를 승인하신다면 제안하는 안전장치**: ① 크레딧 상한을 정해 주세요(예: 최대 ○○ 크레딧). ② 첫 1장만 생성한 뒤 실제 차감량을 보고 → 그 단가로 남은 계획 재산정 → 재승인. ③ 매 생성 전 모델·프롬프트·참고 이미지(승인된 월드맵·고나)를 보고. ④ 결과는 항상 격자 정렬·팔레트 고정 후처리 후 제시.
