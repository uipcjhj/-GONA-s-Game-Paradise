원인 (코드 확인):
- 캔버스에 810×1432 원화를 **매 프레임 다시 그림** (확대·이동·색 입히기) — 프레임마다 큰 이미지 합성
- 장면 조명용 **색 입힌 사본 캔버스를 그때그때 생성** (`tinted()` · 장면이 바뀌는 순간 새 캔버스 생성 = 롱태스크)
- 자막·타이틀을 위해 **React 상태를 초당 10번 갱신** → 자막 DOM 재계산
- 효과 문구 `shadowBlur` · 다수 입자 · 흔들림이 같은 프레임에 겹침
- 자막이 **음악 시각표(약 45초)에 고정** → 읽는 속도와 무관하게 사라짐

## 2. 새 구조 (`src/sky/OpeningStory.tsx`)
- 상태: `loading`(다음 그림 받기+decode) → `transition`(디졸브 0.9초) → `textIn`(0.3초) → `wait`(터치 또는 AUTO) → `textOut`(0.25초) → 다음 장면
- 모든 타이머는 '세대 번호'로 묶음 → 장면이 바뀌면 이전 타이머는 아무것도 못 바꿈 · 전환 중 터치는 무시 · 자막 등장 중 첫 터치는 즉시 완성
- 그림: DOM `<img>` 두 겹. 다음 그림은 **decode() 끝난 뒤에만** 투명(0)으로 깔고 두 프레임 뒤 opacity 1 (CSS 0.9초) → 끝나면 이전 겹 제거. 준비가 늦으면 지금 장면을 그대로 유지
- 미리 받기: 시작 전 1·2장면 · 이후 뒤에서 순서대로 전부 · 장면마다 다음 2장면
- 움직임: 기본 정지. 잠드는 장면(아주 느린 위로 패닝) · 출격(14초 동안 5% 다가감) · 꿈속 고나(부유)만 — transform 만
- 진행은 `click`(손 뗀 뒤 한 번) → 화면이 바뀐 자리의 버튼이 눌리는 유령 클릭 방지
- 조작: 화면 터치=다음 · ◀ 이전 대사 · AUTO · ❚❚ 일시정지(앱을 내리면 자동) · SKIP

## 3. 시간
- 디졸브 900ms · 자막 등장 300ms · 자막 사라짐 250ms (측정값은 timing.json)
- 수동: 터치할 때까지 무제한 유지
- AUTO 읽기 시간 = 1.8초 + 글자당 0.15초 (공백·기호 제외) · 최소 3.2초 · 최대 9초 · 전환 시간 미포함
- 대사 없는 '잠드는' 장면만 2.6초 머문 뒤 자동 진행
