# iPhone Safari 실기기 테스트 절차 (공개 배포 없이)

> 자동 테스트는 모두 Chromium 에뮬레이션(393×636 · 390×844)입니다. **실제 iPhone Safari 결과가 아닙니다.** 아래 절차로 직접 확인해 주세요.

## 1. 로컬 미리보기 띄우기 (현재 브랜치 그대로, 외부 공개 없음)
```bash
git fetch origin claude/platform-home && git checkout claude/platform-home
npm ci
npm run build
npx vite preview --host --port 4173      # 같은 Wi-Fi 의 iPhone 에서 접속
```
- 터미널에 나오는 `Network: http://192.168.x.x:4173/` 주소를 iPhone Safari 에 입력.
- 게임천국: `http://<PC주소>:4173/` · Mini Game Land 바로가기: `http://<PC주소>:4173/mini-game-land/`
- (선택) Food 연동까지 보려면 Food 저장소(`/home/user/gona`, 패치 적용본)를 `npx vite build --outDir ../-GONA-s-Game-Paradise/dist/GoNa` 로 빌드해 같은 서버에 올리고, `src/data/islands.ts` 의 Food `url` 을 `./GoNa/` 로 바꾼 **로컬 전용** 빌드로 시험(커밋 금지).
- 회사·공용 Wi-Fi 에서는 기기 간 접속이 막힐 수 있음 → 휴대폰 핫스팟에 PC 를 붙이면 됨.

## 2. 확인 항목 (체크리스트)
| # | 항목 | 방법 | 기대 결과 |
|---|---|---|---|
| 1 | 첫 소리 | 타이틀을 터치 → 월드맵 | 첫 터치 뒤에 효과음·홈 BGM 이 남. 터치 전에는 무음 |
| 2 | BGM 중복 | 프로필·랭킹·MORE·설정을 빠르게 10번 오가기 | BGM 이 겹치거나 빨라지지 않음 |
| 3 | 잔류 재생 | 홈 버튼으로 Safari 를 내렸다가 다시 열기 / 다른 탭으로 갔다 오기 | 숨겨진 동안 소리 없음, 돌아오면 이어서 |
| 4 | 음소거 | 설정 → 효과음 끄기 / BGM 끄기, Mini Game Land 홈 → 소리 꺼짐 | 즉시 조용해지고 다시 켜면 돌아옴. 무음 스위치(벨소리) 켠 상태도 확인 |
| 5 | 게임 전환 | 미니게임천국 입장 → 게임 시작 → 일시정지 → 그만두기 → 게임천국 | 메뉴곡 → 게임곡 → 메뉴곡, 게임천국 복귀 시 홈곡 하나만 |
| 6 | 터치 | 편가르기 스와이프·분류함 탭, 탑 드래그·두 손가락 회전·교환, 장난감방 탭→탭 | 지연 없이 반응, 탭이 두 번 먹지 않음, 화면이 스크롤·확대되지 않음 |
| 7 | 탑 오입력 | 조각이 가라앉는 동안 화면을 눌렀다 떼기 | 새 조각이 저절로 떨어지지 않음(다시 눌러야 함) |
| 8 | 화면 잘림 | 세로 / 가로 회전, 주소창 접힘·펼침 | 버튼·점수판이 노치·홈 바에 가리지 않음, 가로 스크롤 없음 |
| 9 | 프레임 | 탑 L9~10(조각 많음), 장난감방 L10 | 끊김 없이 움직임(체감) |
| 10 | 결과·보상 | 한 판 끝내고 게임천국 복귀 | 결과 화면 1번만, 점수 카운트업·레벨업·코인, 새로고침해도 다시 안 뜸 |
| 11 | 움직임 줄이기 | 설정 → 움직임 줄이기 켜기 (또는 iOS 설정 → 손쉬운 사용 → 동작 줄이기) | 반짝임·튀는 연출이 멈추고 기능은 그대로 |
| 12 | 저장 | Safari 를 완전히 종료 후 다시 열기 | 닉네임·기록·코인 유지 |
| 13 | 인앱 브라우저 | 카카오톡 등으로 주소를 열기(393×636 에 가까움) | 위와 동일 |
