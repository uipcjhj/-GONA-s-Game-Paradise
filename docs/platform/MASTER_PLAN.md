# GONA GONE WILD! 게임천국 통합 플랫폼 — 마스터 플랜 (설계안 v0)

> 상태: **설계 단계 (개발 없음)**. 승인된 타이틀·오프닝·월드맵 에셋/디자인은 변경하지 않는다.
> 시안: `docs/platform/prototype/index.html` (정적 프로토타입, 운영 코드와 분리) · 캡처: `docs/platform/screens/`
> 화면의 이름·점수·순위는 전부 **시안용 샘플**이며 실제 기록이 아니다.

## 1. 비전
게임천국을 "게임 링크 모음"이 아니라 **하나의 콘솔 게임 메뉴**로 만든다. 플레이어는 닉네임 하나로 시작(A안: 회원가입·이메일·비밀번호·소셜 로그인 없음)하고, 월드맵(허브)에서 섬을 골라 게임을 즐기며, 기록·XP·코인·업적·도감이 하나의 프로필에 쌓인다. 온라인 랭킹 서버가 없어도 앱은 **완전히 동작**한다(로컬 우선).

원칙
1. 타이틀 화면은 그대로 둔다(미등록 → 등록 유도, 기존 플레이어 자동 인식, 저장 손상 복구 안내, 첫 방문 환영만 연결).
2. 월드맵이 허브. 섬·고나·터치영역은 같은 이미지 좌표계(`src/data/world.ts`) 유지.
3. 로컬 우선 + 서버는 선택(어댑터). 서버가 없으면 "온라인 랭킹 미연결"이라고 **정직하게** 표시, 가짜 순위 금지.
4. 코인은 무료 게임 재화(현금 결제·능력치 아이템 없음). 점수·XP·코인은 분리.
5. 신규 이미지는 먼저 목록을 제안하고 승인 후 제작. 승인된 에셋을 CSS/Canvas 그림으로 대체하지 않는다.

## 3. 사용자 흐름
```
앱 실행 → 오프닝(2초, 재방문 생략) → 타이틀
  ├ 플레이어 없음 → [닉네임 등록 3단계: 이름 → 아바타 → 환영] → 월드맵
  ├ 플레이어 있음 → 월드맵 (HUD에 내 정보)
  └ 저장 손상 → "기록을 복구할 수 없어요" 안내 → 백업 복구 / 새로 시작
월드맵 → 섬 탭 → 섬 팝업 → PLAY(게임 실행, 세션 시작) → 게임 종료 → 결과 기록 → 월드맵 복귀(보상 토스트)
          └ 랭킹 버튼 → 해당 게임 랭킹
하단: WORLD / PROFILE / RANKING / MORE(업적·도감·미션·상점·설정)
```

## 5. 기능 상세 명세
### 5.1 플레이어 / 닉네임
- 가입 없음. 첫 실행 시 `playerId`(UUID) 로컬 생성. 서버 연결 시 서버가 발급한 ID/토큰으로 교체(ARCHITECTURE 참조).
- 닉네임: 한글·영문·숫자 2~10자, 공백/특수문자 불가, 부적절 표현 사전 검사. **중복 허용**, 랭킹에는 `#식별코드(4자, 혼동 문자 제외)` 병기. 변경해도 기록 유지. **닉네임은 소유 증명이 아님.**
- 아바타 5종: 고나·딸기·쿠키(기존 PNG 재사용), 알·별(임시 도트 → **신규 에셋 승인 필요**).
### 5.2 월드맵 허브
HUD(좌상단 플레이어, 우상단 코인·알림) + 지도 + 하단 4탭. 섬 3개 유지(Food 플레이 가능, Sky/Mini COMING SOON). 393×636에서 섬·고나가 가려지지 않아야 함(HUD 배치는 승인 결정 D1).
### 5.3 랭킹
- 주간: KST 월 00:00 ~ 일 23:59:59. 역대: 개인 최고, 동점은 먼저 달성 우선.
- 종합: 게임별 순위를 **백분위 점수**로 환산(원점수 합산 금지), 게임별 최소 참가자 수 미달 시 반영 보류, 2개 이상 게임 참여 필요, 미출시/미참여는 0. 신규·소규모 게임이 불리하지 않도록 shrinkage `n/(n+m)` 적용.
- 상태: 로딩 / 네트워크 오류 / **미연결(가짜 순위 금지)** / 정상.
- 후속: 가족/친구 랭킹(초대 코드).
### 5.4 진행(XP·레벨·코인)
점수/XP/코인 분리. 예) 레벨 곡선 `xpToNext(L)=100+40(L−1)`. 게임당 XP·코인에 **일일 상한**과 1회성 보너스. 코인은 꾸미기 전용.
### 5.5 업적·칭호 · 도감 · 미션 · 상점
- 업적: 공통 + 게임별, 진행률/보상/칭호. 중복 달성 방지(서버/로컬 모두 idempotent).
- 도감: 캐릭터·가족·보스·몬스터·간식·아이템·특별. 미발견은 "?". 이미지 없는 항목은 게임 개발 시 에셋 요청.
- 미션/출석: KST 날짜 기준. 오프라인은 **기기 시계 조작 가능**하므로 보상은 소액·무가치 재화만.
- 상점: 아바타/테두리/칭호/배경. 구매 확인창 필수. pay-to-win 없음.
### 5.6 설정 · 백업
BGM/효과음/볼륨/진동/모션 줄이기/닉네임/아바타/백업·복구/초기화/정보. 백업: 파일 내보내기·가져오기 먼저, **비밀 복구 코드**는 온라인 연결 후(공개 식별코드와 분리). Safari 데이터 삭제·기기 변경 시 기록 손실 경고.
