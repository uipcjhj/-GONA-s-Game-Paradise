# 실제 iPhone 확인 항목 (자동 테스트로 대체할 수 없는 것)

자동 테스트(393×636 · 390×844)는 Chromium 모바일 **에뮬레이션**이다. 아래는 Safari / 인앱 브라우저(카카오톡·인스타그램 등)에서 사람이 확인한다. 각 항목에 기기·iOS 버전·브라우저를 적어 둘 것.

## 공통 (Safari 와 인앱 브라우저 각각)
- [ ] 첫 진입: 타이틀 → 오프닝 → 월드맵. 주소창이 접히고 펴져도 화면이 잘리지 않는가(393×636 인앱 기준이 가장 좁다)
- [ ] 가로 스크롤·핀치 확대·당겨서 새로고침으로 화면이 흔들리지 않는가
- [ ] 하단 홈 인디케이터/탭바에 버튼이 가려지지 않는가(safe-area)
- [ ] 섬 터치 좌표가 실제 손가락 위치와 맞는가, 팝업이 고나/섬을 가리지 않는가
- [ ] 홈탭: 프로필 · 랭킹 · 업적 · 도감 · 미션 · 출석 · 상점 · 설정 · 결과 화면 — 글자 잘림·겹침 없음, 버튼이 손가락으로 쉽게 눌리는가(특히 탭 줄·뒤로 `‹`·스위치)
- [ ] 소리 설정: 첫 터치 후 소리가 나는가, 진동 설정(iPhone Safari 는 진동 미지원 — 안내 문구 확인)
- [ ] 저장: 앱 닫았다 열기, 백그라운드 복귀 후 기록이 유지되는가 / **사생활 보호 모드**에서 저장 실패 안내가 나오는가
- [ ] 백업 파일 저장(공유 시트/다운로드)·복원이 되는가(iOS 는 파일 앱 경로가 다름) — 가입 화면의 "백업 파일로 복원"도 확인

## 게임별
- [ ] **Food**: 월드맵 → 입장 → 한 판 → 게임 오버 → "게임천국으로" → 결과 화면·보상. 일시정지/홈 화면 갔다 오기. 엔딩 후 복귀 버튼이 엔딩 버튼과 겹치지 않는가. 체크포인트 이어하기
- [ ] **Sky**: 가로 모드 회전 시 화면, 차지/폭탄 버튼 위치(엄지), 손가락 이동 시 화면 끌림 없음, 일시정지, 결과 → 월드맵
- [ ] **Mini**: 편가르기 스와이프, 탑 쌓기 터치, 장난감방 드래그가 스크롤과 충돌하지 않는가
- [ ] 같은 기기에서 **세 게임을 번갈아** 한 뒤 프로필 기록·랭킹 숫자가 맞는가

## 네트워크(온라인 랭킹을 켠 뒤)
- [ ] 와이파이/LTE 전환·비행기 모드에서 점수 제출 실패 시 앱이 멈추지 않고 재시도하는가
- [ ] 다른 기기에서 같은 닉네임으로 등록해도 기록이 섞이지 않는가
