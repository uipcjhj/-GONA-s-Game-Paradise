## 2. Food 보스 재도전 (`tools/live-boss-e2e.cjs` 21/21)
- 테스트 진입: Food 에 **이미 있는** 개발용 `?test=<보스>`(`__DEV_TOOLS__` 게이트). **Food 소스 수정 없음 → 난이도·보스 행동 불변.** 정식 Food 빌드(`/tmp/food-prod`)에는 `기능 테스트 메뉴`·`__gona` 문자열 0건 확인.
- 흐름(실제 터치·실제 피격): 뽀뽀괴물전 사망 → "뽀뽀괴물전 다시" → 같은 보스·같은 체력으로 재시작 → 재사망. 킁카괴물(최종)전 사망 → "이어하기 · 최종 보스부터"(Food 규칙: 같은 위치라 한 버튼만) → 보스 격파(마지막 일격만 개발 훅 보조) → 엔딩 → 클리어 결과.
- 결과: 판마다 결과 정확히 1건(총 4건: 실패 3 + 클리어 1, resultId 모두 다름), 엔딩 연출 중 추가 전달 없음, Paradise 쪽 플레이 4·클리어 1·원장 4·XP/코인 합계 = 누적 지급(이중 지급 없음), 새로고침 후 불변.
- **점수 이월 규칙 정정**: 재도전은 "사망 점수 이월"이 아니라 **보스 진입 시점 점수로 복원**(Food `retryCarry`, 체크포인트도 저장 시점 점수). 이전 문서/테스트의 가정을 이 규칙으로 바로잡음. 사망 점수가 이어지지 않으므로 점수 이중 계산 없음.
- 한계: 보스 진입 점수·마지막 일격은 개발 훅으로 설정(정상 진행 경로 전체를 사람이 하는 검증은 `IPHONE_CHECKLIST.md`).

## 3. 통합 + 스트레스 (`tools/rc-integration-e2e.cjs`, 393×636 · 390×844 각 20/20)
한 계정으로 Food(실제 보스전 사망)·Sky(게임 오버+클리어)·Mini(실제 라운드) 후: 기록(Food 1·Sky 2/클리어 1·Mini 1)·원장 4·보상 일관·업적·프로필·랭킹(로컬 표시, 가짜 순위 없음). 같은 데이터 위에서 새로고침 / 중복 결과(같은 resultId) / **저장 공간 부족**(안내 → 다시 시도 → 한 번만 반영) / 백업 → 초기화(gp.v1.* 삭제·Food 키 보존) → **복원** / 두 탭 동시 수신 모두 통과.
- **발견·수정한 결함**: 초기화 후·새 기기에서 복원할 방법이 설정(플레이어 필요)·손상 화면뿐이라 **가입 화면에 "백업 파일로 복원" 추가**(복원 후 바로 월드맵).
- **온라인 랭킹 구분**: 이 e2e 는 온라인 서버를 쓰지 않음(로컬 표시만). 온라인은 `platform-online-e2e`(로컬 테스트 서버 `localhost:8787`, SQLite 에뮬레이터, 시드 "테스트 플레이어") 18/18 × 2. **운영 서버는 존재하지 않음**(미생성) — `CLOUDFLARE_SETUP.md` 1절.
