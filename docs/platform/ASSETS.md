# 에셋 구분표 (임시 vs 정식) — 이번 단계 신규 이미지 생성 없음

| 구분 | 위치 | 현재 시안 | 정식 계획 | 필요 시점 |
|---|---|---|---|---|
| **승인된 기존 에셋 (그대로 사용)** | 월드맵 배경, 고나 스프라이트, 타이틀/로고, 갤러리 폰트 Galmuri11, 기존 `PixelIcon`/`PixelLeaf` | 사용 | 변경 없음 | — |
| **기존 에셋 재사용** | 아바타 고나(`gona.png`)·딸기·쿠키(Food 저장소 `public/assets/snacks/*.png`의 **복사본**), 섬 팝업 썸네일(승인된 월드맵 크롭) | 사용 | 딸기·쿠키 PNG를 Paradise `public/assets/avatars/`로 복사(Food 저장소는 수정하지 않음) | Phase 1 |
| **임시(시안 전용, 운영 코드 금지)** | 아바타 알·별 → 코드 도트 + 빨간 점선 / 하단탭·MORE 아이콘 / 코인·XP 막대 / 업적 별·잠금 아이콘 / 도감 별 | 코드로 그린 임시 도트 | 정식 PNG로 교체 | — |
| **정식 에셋 필요 (신규 제작, 승인 후)** | ① 아바타 알·별 (각 32×32 PNG) | 임시 | 정식 픽셀 PNG 2종 | Phase 1 후반 or 6 |
| | ② 코인 아이콘, 레벨 배지 프레임, XP 막대 타일 | 임시 | PNG/9-slice | Phase 3 |
| | ③ 랭킹 메달(1/2/3위), 트로피 아이콘 | 임시 | PNG | Phase 4 |

| | ⑥ 상점 꾸미기(테두리·배경·칭호 장식) | 임시 | PNG | Phase 6 |
| | ⑦ 섬 팝업 전용 대표 이미지 | 월드맵 크롭(승인 에셋) | 필요 시 별도 제작 | 선택 |

**Phase 1 운영 반영 원칙**: 신규 이미지 없이 진행. 알·별은 운영 화면에서 **잠금 슬롯("준비 중")** 으로 표시(임시 CSS 그림 노출 금지), 정식 에셋 승인·제작 후 열기. 선택 가능한 아바타는 고나·딸기·쿠키 3종.
이미지 제작이 필요해지면 목록·해상도·크레딧 비용을 먼저 제안하고 승인 후 진행한다.
