# HUD 배치안 비교 (D1: 월드맵·로고 헤더 유지, 지도 축소 최소화)

기준: 운영 월드맵 레이아웃(헤더 48px + 하단 메뉴 66px 사이에 지도)을 그대로 두고, **플레이어 정보는 작은 버튼 중심**으로 재설계. 이전 시안(v0)은 헤더 아래 44px HUD 줄을 추가해 지도가 줄었다 → 폐기.

| | 안 A 지도 위 오버레이 | **안 B 헤더 내장 (추천)** | 안 C 하단탭 아바타 |
|---|---|---|---|
| 구성 | 좌상단 작은 아바타+LV 버튼, 우상단 코인칩을 지도 위에 띄움 | 로고 헤더 좌측 플레이어 버튼(아바타·닉·LV·XP), 우측 코인칩. 양옆의 장식 별 2개 자리 사용 | 헤더 그대로, PROFILE 탭이 아바타+LV 배지, 코인칩만 지도 우상단 |
| 지도 크기 손실 (393×636) | 0px (지도 482px 높이 그대로) | **0px** | 0px |
| 지도 가림 | 지도 상단 모서리 일부(바다/구름 영역 ~40×50px) | **없음** | 우상단 코인칩 ~60×22px |
| 닉네임·XP 노출 | 아바타+LV만 | **닉네임·LV·XP 바 모두** | 아바타+LV 배지만 |
| 터치 타겟 | 40×50 | 34 높이(헤더 48px 안) | 탭 영역 그대로 |
| 승인된 로고 헤더 변경 | 없음 | 장식 별 2개를 버튼으로 대체(로고·문구·색은 그대로) | 없음 |
| 단점 | 지도 위에 UI가 떠 있어 아트 훼손 느낌 | 좁은 폭(≤360px)에서 닉네임 말줄임 | 내 정보가 한눈에 안 보임 |

측정(Playwright, 지도 `#fit` 크기): 393×636 → 393×482, 390×844 → 390×478. 세 안 모두 운영과 동일(손실 0).
**추천: B.** 정보량이 가장 많고 지도를 전혀 가리지 않는다. 로고 헤더의 별 장식 대체가 부담이면 C로 후퇴(별 유지).
알림 벨은 HUD에서 제거하고 MORE 탭의 빨간 점으로 대체(터치 요소 최소화).
