## 2. 배포 구조와 충돌 위험
- GoNa 저장소 `pages.yml`(main·dev 푸시 시 실행): main → `/GoNa/`, dev → `/GoNa/dev/`. **sky-test 폴더를 모르기 때문에** 이 워크플로가 돌면 `/GoNa/sky-test/` 가 사라진다 (이전 세션에서 확인).
- GoNa `pages-sky-test.yml`(sky-test 브랜치 푸시 시 실행): main·dev 를 다시 빌드하고 `sky-test/` 만 추가. 같은 Pages 사이트를 공유하므로 **새 폴더를 추가하는 것도 같은 방식이어야** 하고, 이는 다른 게임 배포 설정 변경에 해당 → **사전 승인 필요**.
- 결론: 안전한 별도 URL 은 아직 없다. 승인 전까지 **로컬(dist-poop)에서만 검증**.
- 제안 (승인 요청 사항): GoNa 에 `sky-poop` 브랜치 + 워크플로를 추가해 `/GoNa/sky-poop-test/` 를 배포. 기존 `sky-test` 워크플로와 동일한 구조, 검사 단계에서 `sky-test/` 존재 여부를 함께 확인.

## 3. 현재 엔진 구조 (재사용 대상)
- 해상도: **논리 180×320**, 캔버스 2배(360×640) 표시 — 요청서의 "270×480" 과 다름. 아트 명세는 실제 렌더 기준으로 작성.
- `src/sky/engine.ts` (약 3,000줄): 대본(`Step`) 기반 편대·중간보스·3페이즈 보스·레이저·탄막 패턴·가족 동료·필살기·근접·차지.
- `src/sky/stages.ts`: 난이도(`DIFF`), 스테이지 6개, 보스 정의(`BossDef`), 대본(`S1..S6`).
- `src/sky/SkyGame.tsx`: 타이틀 → 선택 → 출격 → 결산 → 컨티뉴 → 엔딩 → 크레딧 흐름, 기록 저장.
- `src/sky/audio.ts`: 스테이지별 BGM 지연 로드, 효과음 인라인.
- 재사용 가능: 엔진 전체, 가족 6명 전투 시스템, 난이도, 기록, 오디오 구조, 자동 조종 봇·DPS 측정 도구.

## 5. 임시 · 재활용 목록
- 재사용(유지): 가족 원화 6명 + 고나, 동료 날개 스프라이트, 고나 스프라이트, 키아트, 로고, 엔진/오디오/기록.
- 임시(교체 필요): 스테이지 2~6 배경·적·보스 (케이크 버전 색변환), 스테이지 1 적·보스 (쌀떡 골렘·장군 등 신규 명칭은 **이름만 바뀐 임시 연출**).
- 금지 준수: 기존 케이크 에셋은 삭제하지 않음. 응가 팩은 같은 파일을 읽되 명칭·대사만 교체.

## 6. 위험 목록
1. Pages 공유: 새 경로 배포는 승인 필요 (2번 참고).
2. 기록 충돌: 응가 빌드는 `gona.skypoop.*` 저장 키 사용 → 케이크 기록과 분리 (검증 완료, 6번 문서 참고).
3. 화풍 불일치: 가족 원화(셀 일러스트)와 적(픽셀 스케일)의 표현 차이가 큼 → 신규 적·보스는 같은 픽셀 밀도로 맞춰야 함. 현재 툴 미연결로 제작 불가.
4. 음악: 스테이지 1 BGM 은 케이크 버전과 같은 곡 — 응가 팩 전용 곡 없음 (명세 필요).
