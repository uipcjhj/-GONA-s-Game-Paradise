# PHASE 1 — 아트 디렉션 · 에셋 명세 (응가 대탈출 팩)

> 상태: **명세 문서**. 이미지 생성 도구(ChatGPT · Nano Banana)가 이 세션에 연결되어 있지 않아 **신규 그림은 한 장도 만들지 않았다**. 아래 명세대로 제작하면 엔진에 바로 넣을 수 있게 파일명·크기·레이어를 맞춰 두었다.

## 1. 아트 원칙
- 기존 케이크 버전과 **같은 작품처럼** 보여야 함: 같은 밝은 황혼 하늘 팔레트, 같은 굵은 외곽선, 같은 가족 원화 화풍.
- 적·보스는 **실제 표시 크기에서** 읽히게: 적 27~57px, 보스 110px. 원본은 표시 크기의 **2배 이상** (예: 표시 27px → 원본 64px 이상).
- 픽셀 밀도: 적·보스는 "1 게임 픽셀 = 원본 2×2 픽셀" 규칙 (논리 180×320 기준). 배경은 `bg-backdrop` 과 같은 360×640 (2배 표시).
- 명도 단계: 밝은 면 · 중간 · 어두운 면 3단계 + 하이라이트 1점. 그라데이션 금지.
- 탄환 가독성: 적 탄은 배경과 다른 **채도 높은 색 + 밝은 테두리**. 배경 밝기가 탄 밝기와 비슷하면 안 됨 (배경 근경 오브젝트는 탄 경로 위에 두지 않음).
- 금지: 색 필터만 바꾼 재활용, 단순 원·사각형 몬스터, 저해상도 확대, AI 한 장을 배경 전체에 붙이기, 화풍 혼합.

### 보스 페이즈별 외형 (거대 쌀떡 골렘)
- **1페이즈** 하얀 쌀떡 몸체, 오른팔 주먹 + 포탑 2개 (그릇 모양).
- **2페이즈** 떡 표면이 갈라져 붉은 소스가 흐름, 포탑 한 개 파손 (파손 프레임 `boss-p2-hit.png`).
- **3페이즈** 떡이 굳어 바위처럼 변함, 가운데 코어(노란 쌀알)가 노출. 최종 격파 시 파손 연출 2프레임.
- 파손·연기·폭발 프레임은 기존 `fx-explosion` 과 같은 크기(320×80 시트 기준)로 맞춘다.

## 4. 오프닝 · 엔딩 컷신 콘티 (실제 구현은 기존 원화 + 텍스트)
- 현재 구현: 정지 원화 6장 + 자막, 터치 스킵 · 첫 플레이 자동 · 타이틀 '오프닝'으로 다시 보기.
- 연출 2D 애니메이션 (1~10 장면 콘티):
  1. 식탁 — 고나가 이유식을 먹음 (엄마 · 아빠 · 이모 · 할머니 · 할아버지 · 삼촌 모두 보임)
  2. 배 클로즈업 — `꾸르르륵` 텍스트 흔들림
  3. 고나 얼굴 빨개짐 — 힘주는 표정 3프레임
  4. 울음 — 눈물 1프레임
  5. 가족 달래기 — 엄마·아빠 손 흔들림
  6. 고나 잠듦 — 화면 어두워짐
  7. 배 속 줌인 → 꿈 전환 (크로스 페이드)
  8. 소화왕국 등장 — 거대 숟가락 + 이유식 강 (배경 애니 2프레임)
  9. 익룡 슈트 변신 — 고나 3프레임 변신 (`gona` 원화 기준, 얼굴 비율 유지)
  10. 가족 수호자 선택 후 출격
- 엔딩 콘티: 소화왕국 환호 → "해냈고나!" → 정적 → "뿡!" → 가족 반응 4컷 → "세상에서 가장 작은 영웅의, 가장 위대한 탈출."

## 6. 파일 · 폴더 규칙
- 위치: `public/assets/sky/v3-poop/stage1/…` (케이크 원본 `v2/` 는 그대로 둠).
- 파일명: `<영역>-<이름>[-프레임|-p<페이즈>].png` (예: `stage1/boss-p2-hit.png`).
- 기준점: 적·보스는 **중심 하단** 기준, 배경은 **좌상단 (0,0)** 기준. 각 파일 옆 `.json` 에 크기·기준점 기록 (미작성 상태).

## 7. 검수 기준 (에셋 받은 뒤)
1. 투명 배경 · 가장자리 잘림 없음 · 원본 크기 명세 일치.
2. 표시 크기 (2× 축소본)에서 실루엣이 식별되는가.
3. 배경 위 탄 가독성: 탄 색과 배경 평균 밝기 차이.
4. 케이크 원화와 나란히 놓고 굵은 외곽선·색감·명도 단계가 같은가.
5. 모바일 393×636 · 390×844 스크린샷에서 가로 넘침 없음.
