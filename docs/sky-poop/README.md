## 구현 방식 (기존 버전 보존)
- 테마 팩 `src/sky/theme.ts`: `cake`(기본, 기존 문구 그대로) · `poop`(신규). 빌드 때 `VITE_SKY_THEME=poop` 로 선택.
- 엔진·가족 시스템·난이도·기록은 공유. 응가 빌드는 기록 저장 키를 `gona.skypoop.*` 로 분리 → 케이크 기록과 섞이지 않음.
- 케이크 빌드를 검증: 타이틀 문구 · 스테이지 이름 · 보스 이름 · 오프닝 없음 — 기존과 동일.

## 빌드 · 실행
```bash
npm run build          # 기존 케이크 버전 (dist/)  — 변화 없음
npm run build:poop     # 응가 대탈출 테스트 빌드 (dist-poop/) — 로컬 검증용
```
- 배포는 아직 하지 않음. `/GoNa/sky-poop-test/` 경로는 GoNa 배포 설정 변경이 필요해 **승인 대기** (`00-phase0-analysis.md` 2번).

## 이번에 확인한 것 (자동화 · 로컬)
- 타입 검사 · 케이크/응가 빌드 모두 통과.
- 응가 빌드: 타이틀 부제 표시 → PRESS START → 첫 플레이 오프닝 자동 재생 → 건너뛰기 → 선택 화면 → 스테이지 1 시작 (이름 `이유식 왕국의 반란`, 보스 `거대 쌀떡 골렘`, 중간보스 `이유식 냄비 장군`). 두 번째 실행부터는 오프닝 자동 재생 없음. 콘솔 오류 0, HTTP 오류 0.
- 케이크 빌드 회귀: 타이틀 `6 STAGES · 개발판`, 오프닝 버튼 없음, 스테이지 1 `황혼의 부유왕국` / `러브 크러셔` / `강철 포함` — 기존과 동일. 콘솔 오류 0.

## 검증되지 않은 것 (정직하게)
- **실기기**: iPhone Safari · Android Chrome · PC 실제 플레이 — 미확인.
- **60fps**: 응가 빌드의 성능 측정 미실시 (케이크 버전 기준 측정치만 있음).
- **밸런스**: 응가 팩 전용 드롭률·난이도 튜닝 없음. 케이크 버전의 1차 개편(`docs/sky-balance/README.md`)을 그대로 이어받음.
- **오디오**: 응가 팩 전용 음악 없음 — 케이크 BGM 재사용. 중복 재생 점검은 자동 조종 흐름에서 오류 없음만 확인.
- **스테이지 2~6**: 이름·대사만 교체, 그래픽·패턴은 케이크 버전과 동일 (임시 표시됨).
- **신규 테스트 URL**: 없음 (로컬 빌드만).
