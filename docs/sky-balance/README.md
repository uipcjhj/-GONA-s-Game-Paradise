# GONA's Sky Adventure — 가족 밸런스 · 근접 공격 · 회복 보급 개편 (1차)

**상태: 개발 브랜치 임시 빌드 · 공개 테스트판(/GoNa/sky-test/)은 아직 그대로 둠 · main 미반영**

## 1. 측정 방법 (`tools/sky-dps.cjs`, 결과 JSON: `docs/sky-balance/`)
- 고나는 제자리, 체력 무한 가상 표적 2개 (고나 바로 위 · 동료 위치). 표적은 한 객체로 고정 (재생성하면 한 탄이 두 번 맞는 오류가 생김).
- 30초 자동 사격 DPS (고나 기본 사격 + 동료 공격, 출처별 분리).
- 차지 1발 순수 가치 = (충전 구간 피해 − 무충전 대조 구간 피해) + 충전 중 멈춘 기본 사격 피해.
- **한계**: 표적이 가만히 있어 명중률은 실제 적 움직임을 반영하지 않음. 사람 플레이 아님.

## 2. 측정 결과 (전후 비교)
| 가족 | 동료 공격 (전 → 후) | 전체 DPS (전 → 후) | 차지 1발 순가치 (전 → 후) |
|---|---|---|---|
| 엄마 | 0 (하트가 표적에 안 닿음) → 2.5 (전방 하트 부채꼴) | 10.8 → 13.3 | 76(2표적 합) → 28 (단일 관통 빔) |
| 아빠 | 13.4 (관통 빔, 2.5초마다) → 3.7 (굵은 직선 볼트) | **24.2 → 14.5** | 76 → 33 (관통 충격파) |
| 이모 | 6.1 (유도 별) → 3.9 (직선 별 3발, 자동 유도 없음) | 16.9 → 14.7 | 76 → 31 (관통 스타 캐논) |
| 할머니 | 2.4 → 1.8 (포션, 자동 회복 제거) | 13.2 → 12.6 | 76 → 38 (폭발 플라스크, 주변 절반 피해) |
| 할아버지 | 2.3 → 2.3 (창, 그대로) | 13.1 → 13.1 | 76 → ~0 (근접 충격파: 46px 안만 피해 · 탄 소거 중심) |
| 삼촌 | 4.4 (유도 전기) → 5.3 (직선 전기 2발) | 15.2 → 16.1 | 76 → 52 (폭발 미사일, 주변 절반 피해) |

- 기본 사격(고나)은 모든 가족 동일 10.8 DPS. 차지 중에는 기본 사격이 멈춤 (1초 충전 = 기본 사격 약 11 피해 손실).
- 차지 값 "전"은 두 표적 합계, "후"는 가족별 단일 표적 기준이라 직접 비교는 주의.

## 3. 바뀐 것
- **아빠**: 빨간 레이저 같은 광역 빔 제거 → 굵은 직선 볼트. 차지는 빨리 차는 관통 충격파. 필살기 스팀 브레이커는 그대로.
- **엄마·이모·삼촌**: 일반 공격 자동 유도 제거 (필살기에서만 유도 유지). 엄마 하트는 전방 부채꼴.
- **할머니**: 14발마다 자동 회복 제거 → 스테이지 회복 보급(난이도별) 안에서만. 필살기 보호막은 5초 → 3초.
- **할아버지**: 차지 = 즉발 방패 충격파 (주변 탄 소거 + 근접 피해). 장거리 피해 낮음 (의도).
- **삼촌**: 차지 폭발 미사일 — 맞은 적 주변 절반 피해 (검증 완료: 두 표적 모두 피해).
- **근접 공격 (신규)**: '근접' 버튼 (키보드 V). 앞으로 0.32초 돌진, 적·탄에 닿아야 맞음, 돌진 중 짧은 무적, 쿨다운 1.8~3.0초. 피해: 아빠 6 · 할아버지 5 · 삼촌 4 · 엄마·이모·할머니 3.
- **회복 드롭**: 일반 적·증기 건십에게서 딸기 회복이 더 이상 떨어지지 않음. 회복은 **스테이지당 보급 횟수** (쉬움 3 / 보통 1 / 어려움 1)만 사용: 정해진 딸기·할머니 자동 회복·할머니 필살기 공유.
- **P·메달·폭탄 드롭**: 일반 적 P 5%→10%, 메달 12%→8%, 폭탄 2% 유지 (확률 조정 값 — 실제 플레이 로그로 재조정 필요).
