## 0. 원칙
- **기존 승인 원화 유지**: 철벽 똥기사 3프레임(`v3-poop/s5/boss.png` 220×240 ×3: 정상 · 방패 금 · 갑옷 벗음), 부위 시트(`parts.png`), 굳은 응가 골렘(`extra.png`), 응가 성채(`enemy-gunship.png`), 금빛 포탑(`enemy-orb.png`), 배경(`bg-backdrop.png`) — 다시 그리지 않음. 새 이미지는 **이 그림들을 참고 이미지로 넣어** 같은 색·외곽선·도트 크기로 생성.
- **컨셉 이미지 한 장이 아니라 게임용 스프라이트 시트**: 투명 배경 · 칸 크기 고정 · 같은 기준점(바닥 중앙) · 프레임별 동일 배율. 한 번 생성에 한 시트(같은 물체의 상태들)를 받아 일관성 유지.
- 생성 뒤 Claude Code 작업: 칸 자르기 · 투명 정리 · 게임 배율(정수)로 축소 · 팔레트 맞춤 · 시트 배치 · 기준점 정렬 · 충돌 마스크 생성 · 게임 연결.
- 엔진이 직접 그리는 것(원화 아님): 피격 흰 번쩍임(원화 실루엣), 경고선·돌진 경로 표시, HP 바, CHAIN 숫자, 작은 입자 — 기존 규칙상 허용 범위.

## 3. 프레임 구조 설계 (게임 연결 기준)
- **지형 시트** `public/assets/sky/v3-poop/s5/terrain-{rock-s,rock-m,crystal,wall,base}.png`
  - 가로로 상태 칸 + 아래 줄 조각 칸 · 칸 크기 고정 · 기준점 = 칸 아래쪽 중앙(바닥) · 같은 위치에 겹쳐 상태 전환 시 흔들림 없음.
  - 상태 전환: HP 비율 100~67% 정상 → 66~34% 작은 균열 → 33~1% 큰 균열 → 0 = 잔해(배경처럼 남고 스크롤) + 조각 3~4개가 회전하며 흩어짐 + 재질 폭발(5-A).
  - 충돌: '정상' 칸 실루엣에서 자동으로 마스크 생성 (보스와 같은 방식) → 총알이 실제 그림에 닿은 지점에서 맞음.
- **성벽**: 3구역(왼탑 · 성문 · 오른탑)을 따로 배치해 구역별 HP · 구역마다 [정상 → 파손 → 붕괴 5칸 → 잔해]. 성문 구역 위에 포탑(2-C 받침 + 기존 `enemy-orb`) — 받침이 부서지면 포탑도 추락.
- **똥기사**: 기존 `boss.png` 3칸(페이즈 모습) + 신규 `boss-act.png` 5칸(동작) — 칸 크기·기준점 동일(220×240) → 엔진은 '페이즈 모습' 위에 '동작 칸'을 상황에 따라 교체. 방패·갑옷·창은 기존 부위 시트 방식(칸 + 파손 칸) + 조각 시트(3-B, 3-C).
- **이펙트 시트**: 가로 n칸 · 칸 크기 고정 · 한 칸 0.06~0.1초 · 가산 혼합 없이 그대로(픽셀 느낌 유지) · 적 탄(분홍·보라 외곽선)과 겹치지 않는 금·갈색 계열.
