# GONA 픽셀 디자인 스킬

디자인 작업을 시작하기 전에 이 문서와 프로젝트 루트 `CLAUDE.md` 의 "디자인 규칙"을 읽고, **승인된 에셋**
(`public/assets/gona-world-map.png`, `public/assets/gona.png`)과 지금 화면을 먼저 확인한다.

## 한 줄 방향
"90년대 오락실 게임 속 화면". 웹사이트·앱처럼 보이면 실패. 둥근 카드, 그림자 남발, 그라데이션, 시스템 폰트 느낌 = 금지.

## 작업 순서
1. **현재 화면 기준 캡처** (수정 전): `npm run build && npx vite preview --port 4174` 로 main 빌드를 띄워 두거나 배포본 URL 사용.
2. 별도 브랜치에서 수정. 새 그림이 필요하면 아래 "에셋 워크플로"를 따른다 (CSS 로 그려서 대체 금지).
3. 수정 후 빌드를 띄워 비교 캡처:
   `NODE_PATH=$(npm root -g) node tools/mobile-shots.cjs http://localhost:4173/ http://localhost:4174/ shots`
   → 393×636 · 390×844 에서 홈 + 섬 선택 상태, 가로·세로 스크롤, 팝업 화면 안 여부, 콘솔 오류 검사 + `compare-*.png`(왼쪽 전/오른쪽 후).
4. **이미지를 직접 열어 보고** 아래 체크리스트로 자기 검수 → 문제를 고친 뒤 다시 캡처. 통과한 결과만 사용자에게 파일로 전송.
5. `npm run typecheck` · `npm run build` 통과 후 보고. main 수정은 사용자 "승인, 배포해" 이후에만.

## 시각 체크리스트 (캡처를 보며 하나씩)
- [ ] 월드맵 이미지·고나와 같은 세계처럼 보이는가 (색 · 선 굵기 · 도트 크기 일치)
- [ ] 도트가 굵고 선명한가 (흐린 확대·부드러운 안티앨리어싱·반투명 번짐 없음)
- [ ] 색이 밝지만 살짝 바랜 레트로 톤인가 (순수 #fff/#000/형광색 지양)
- [ ] 일반 웹 UI 같지 않은가 (카드·알약 버튼·머티리얼 느낌 없음)
- [ ] 글자 잘림·겹침 없음, 터치 영역 44px 이상
- [ ] 지도 이미지 왜곡·잘림 없음, 섬 3개 + 광장 + 다리 모두 보임
- [ ] 팝업·메뉴가 섬이나 고나를 과도하게 가리지 않음
- [ ] 이전 화면 대비 확실히 좋아졌는가 (아니면 되돌리기)

## 에셋 워크플로 (이미지 기반 픽셀아트 UI)
- 승인된 이미지(`gona-world-map.png`, `gona.png`)는 **원본 그대로** 사용. 다시 그리거나 CSS/Canvas 로 흉내 내지 않는다.
- 새 UI 조각(버튼 프레임, 팝업 틀, 아이콘, 로고, 별/반짝이 등)이 필요하면 **PNG 에셋**으로 만든다:
  1. 방향 확정(참고: 월드맵의 색·선·도트 크기) → 사용자에게 시안 확인
  2. 이미지 생성: **Higgsfield 사용 중단**. 1순위 ChatGPT 이미지 생성 · 2순위 Google Nano Banana(무료 범위) — 연결 여부부터 확인.
     연결이 없으면 직접 그리지 말고 `docs/sky-art/asset-requests.md` 형식의 요청서를 사용자에게 전달 (유료 도구는 사용자 승인 필수)
  3. 후처리(PIL): 최근접 이웃(NEAREST) 리사이즈, 팔레트 정리, 투명 배경, 정수 배율의 스프라이트 시트로 저장
  4. `public/assets/` 에 넣고 `image-rendering: pixelated`, 정수 배율 또는 이미지 좌표계(`src/data/world.ts`)로 배치
- 9-slice(테두리 늘어나는 틀)·스프라이트 시트 사용 시 코너 픽셀이 뭉개지지 않게 정수 배율만 사용.
- 임시 CSS 도형은 "기능 확인용 임시"로만 허용하고 PR 에 임시임을 명시. 최종 디자인으로 취급 금지.

## 도구 현황 (이 환경)
- Playwright(chromium) 설치됨 → `tools/mobile-shots.cjs` 로 모바일 캡처·터치 회귀·전후 비교.
- Figma: claude.ai 커넥터/플러그인(공식 Figma MCP)을 사용자가 연결·승인해야 사용 가능. 연결되면 `get_design_context`/`get_screenshot` 으로 시안을 읽어 구현.
- 승인된 시안·에셋이 항상 Figma 보다 우선.
